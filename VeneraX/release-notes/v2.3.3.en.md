## What's Changed

### Added
- Editable translation prompt
- Batch actions for collections
- Page count display on comic tiles
- Visual indicator for comics already in a collection
- Reading orientation toggle in reader

### Changed
- Moved reader overflow menu to the top bar for better accessibility
- Folded rare reader actions into a menu to reduce clutter
- Improved collection browsing experience

### Fixed
- AVIF images now fall back to WebP when decode fails
- Type safety guards for episode loading responses
- Deleted history records no longer reappear after background writes
- Tag chips in search no longer crash when viewing collections
- Local comics now correctly resume from last reading position
