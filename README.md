# Mangrove

**漫画 AI 汉化流水线** —— 把外语漫画变成中文的完整工作流。

> 名字取自 *manga* + *grove*：一册册作品连成林。

## 它做什么

一条流水线走完从生肉到熟肉的全过程：

```
下载章节 → 文字检测 → OCR → 翻译 → 擦除原文 → 排版渲染 → 导出
```

它不是又一个阅读器 —— 阅读只是外壳，主体是「翻译」。

## 核心能力

- **多源下载** —— 按章节抓取，支持翻译组分组；缺页可对账、可补救
- **本地 AI 推理** —— 文字检测 + OCR（日 / 中 / 韩 / 英）+ 神经翻译，全部在本机跑
- **翻译工作室** —— 可视化编辑每个文本块：字形、字号、描边、竖排、位置，所见即所得，带完整撤销
- **翻译组管理** —— 同一部作品的多个组分组管理，章节标签按下载状态着色
- **工程互读** —— 与 BallonTranslator 的 `.json` 工程保持**零字节往返**兼容，两边可以互相打开
