# M06 · 零字节往返互操作

> **什么时候读**：两种语言/两个程序**共用同一份配置文件**，且要求"读进来再写回去必须完全相同"时。
> 上级：`../INDEX.md` ｜ 相关：`M03`（静默分歧）

---

## 场景

A 程序（Python）与 B 程序（Dart/JS/…）读写**同一份 JSON**，且 B 的验收标准是
**`diff == 0`**（保存一次不能产生任何伪改动）。

## 三类必踩的坑

### 1. 分隔符

- Python `json.dumps` 的**默认**是 `", "` / `": "`（**带空格**）；
- Dart `jsonEncode` / JS `JSON.stringify` **不带空格**。
⇒ 字面不同 → diff 非零。
**规矩**：跨语言时**显式指定**（Python：`separators=(', ', ': ')`），并在文档里写明；**不要用 `indent`**。

### 2. 浮点数的指数阈

- Python：指数记法的阈值在 `1e16` / `1e-7` 附近，且指数**带符号、至少两位**（`1e+16`、`1e-07`）；
- Dart：阈值不同（如 21 / -6），且**不补零**。
⇒ 同一个数值序列化成不同字符串。
**规矩**：要么统一用字符串承载高风险数值，要么在两侧都走**同一套序列化实现**。

### 3. 键序与"幻影键"

- 如果模型在解析时**物化/补齐了默认字段**，写回时就会多出原文件没有的键（**幻影键**）→ diff 非零。
- **规矩**：走**有序 DOM 透传** —— 不物化键、未知字段**原样保留**、顺序即原顺序。
- **推论**：同一份文件里由不同来源生成的条目，**必须使用同一套键集**。
  （例：OCR 自动生成的块，必须在"默认块模板"之上做修改，而不能自己另起一套键。）

## 其他容易忽略的点

- **"读不到就别回写"**：某可选字段在源文件里不存在时，不要"顺手补上默认值"。
- **派生文件的坐标契约**：如果下游用 `scale = 图宽 / 源宽` 换算坐标，那么一旦你把中间产物**降采样**，
  `scale` 恒为 `1.0` 的假设就变成**谎言** —— 坐标会全错而不报错。**宁可不产出，也不要产出破坏契约的中间文件。**
- **有序集合的稳定排序**：分区、分页、分组写回前必须做稳定排序，否则每次写出的顺序都可能不同。

## 检查清单

- [ ] 两侧序列化参数**逐字段对齐**了吗？
- [ ] 有没有"解析即补默认值"的地方？
- [ ] 未知字段会原样保留吗？
- [ ] 派生文件的坐标/单位契约，是否被下游当成了不变量？
- [ ] 写回前做过稳定排序吗？
