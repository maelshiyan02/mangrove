## 维护规则

- 一篇一个主题；标题写**可执行的规矩**，不写口号。
- 每篇固定四段：**症状 → 根因 → 规矩 → 反例/检查清单**。
- 只写**能迁移**的内容；项目专有事实放 `../memory/appendices/`。
- 新增篇目必须同时更新本表。
