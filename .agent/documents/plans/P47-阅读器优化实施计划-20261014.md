### 6.2 数据源与跳转（与底栏滑条同源，禁止第二套状态）

- 格数 = **`context.reader.maxPage`**（🔴 不是 `totalPages`，见 §2-5）；
- 当前页 = `context.reader.page`（`_ReaderLocation.page`，已驱动底栏滑条）；
- 跳转 = `_ImageViewController.animateToPage(i)`（gallery 走动画，时长沿用 `enablePageAnimation` 语义）；
- `visited`：gallery 用 `index <= current`；continuous 维护"到过的最大 index"，进阅读器时初始化为历史页，向后单调更新、向前回翻不清空（与 comix 一致）；
- 跨章：页轨**只渲染当前章**，章切换跟随现有接续逻辑刷新，不做跨章拼接。

### 6.3 我能做的验证

| 断言（widget test） | 期望 |
|---|---|
| `readerProgressBarPosition='bottom'` 时不构建 `ReaderPageRail` | 树中找不到该组件 |
| `'left'` 时构建，且页格数 == `maxPage`（构造 30 张图 × `imagesPerPage=1`） | 30 格 |
| `'left'` 时底栏 `CustomSlider` 不在树中，页码胶囊仍在 | 功能不丢 |
| 第 k 格颜色：k<current = `primary.withValues(alpha:.55)`；k==current = `primary`；k>current = `onSurfaceVariant.withValues(alpha:.18)` | 三态精确断言 |
| 鼠标进入热区 → 页格宽度 3→24（pump 动画结束） | 宽度 24 |
| hover 第 k 格 → 气泡文本 == `"$k"` | 文本匹配 |
| 点第 k 格 → `animateToPage(k)` 被调用（记录调用序列） | 记录 == [k] |
| gallery LTR 开启章末评论页时，格数 == `maxPage` 而非 `maxPage+1` | 🔴 防 §2-5 那个坑 |

**反向验证**：把 `maxPage` 换成 `totalPages` / 把三态阈值 `<=` 改成 `<` / 去掉热区排除 → 对应断言必须 FAIL。

### 6.4 你在 GUI 做的验收（我会写成步骤清单给你）

1. 6 种阅读模式 × 三类读者（本地素材 / 本地成品 / 网络漫画）各开一次，看三态色与当前页同步；
2. 鼠标进出左缘，看展开/收起是否流畅、气泡页码是否正确；
3. 点第 k 格，看是否跳到该页（gallery 与 continuous 各验）；
4. 无缝跨章：过接续卡后页格数是否刷新、`visited` 是否串行；
5. **左缘翻页热区在轨道以外区域是否仍然有效**（回归）；
6. 设回 `bottom` → 底栏是否完全恢复；
7. 600+ 页章节：密度策略（最小格高 2dp + 轨道内滚动）是否可读；
8. 窄窗 / 最大化 / 多显示器切换。
