# P2-B + P2-A 实施计划：封面收录 + 章节名格式化

## Context

P1 阶段（VeneraX 直读 BT 翻译工程）已完成验收。验收过程中发现三个关联问题：
1. BT 工程封面默认用第一张页图，而非 comix.to 等网站的正式封面
2. 封面查看页的"下载"按钮对本地漫画毫无意义，应改为"打开文件位置"
3. 下载目录名和章节显示包含冗余信息（汉化组+日期），需要拆分格式化

本次实施 P2-B（封面收录）+ P2-A（章节名格式化），涉及 6 个文件。

## Part 1: P2-B 封面收录

### 1.1 BT 工程封面优先读 cover.* 文件

**文件**: `lib/foundation/bt_project/bt_project_manager.dart`

修改 `coverKeyFor` 方法（当前 L112-120），在遍历 `pageOrder` 之前先检查 `cover.*` 文件：

```dart
static String? coverKeyFor(BtProject project) {
  // 1. 先查 directory/cover.{jpg,jpeg,png,webp}
  for (final ext in ['jpg', 'jpeg', 'png', 'webp']) {
    final coverPath = FilePath.join(project.directory, 'cover.$ext');
    if (File(coverPath).existsSync()) {
      return 'cover.$ext';
    }
  }
  // 2. 回退到 pageOrder 中第一个存在的页图
  final key = project.pageOrder.firstWhere(
    (key) =>
        BtProject.isImagePage(key) &&
        File(project.originalPath(key)).existsSync(),
    orElse: () => '',
  );
  return key.isEmpty ? null : key;
}
```

同步修改 `loadCover`（L101-109）：当 coverKey 是 `cover.*` 时，直接读 `directory/cover.<ext>`；否则走原有的 `originalPath(key)` 路径。需增加判断：`coverKey.startsWith('cover.')` 时路径 = `FilePath.join(project.directory, coverKey)`。

`_registerLocal`（L280）中 `coverKey = coverKeyFor(project)` 会自动返回 `cover.*`，无需额外改动。

### 1.2 新增 setCover API

**文件**: `lib/foundation/bt_project/bt_project_manager.dart`

新增方法：

```dart
/// Sets a custom cover for a BT project. Writes the bytes to
/// directory/cover.<ext>, updates the LocalComic cover field, and
/// evicts cached image entries so the UI refreshes immediately.
Future<bool> setCover(String comicId, Uint8List bytes) async {
  final project = await ensureProject(comicId);
  if (project == null) return false;
  final fileType = detectFileType(bytes);
  final coverPath = FilePath.join(project.directory, 'cover${fileType.ext}');
  await File(coverPath).writeAsBytes(bytes);
  // Update LocalComic
  final manager = LocalManager();
  final old = manager.find(comicId, ComicType.local);
  if (old != null) {
    manager.add(LocalComic(
      // copy all fields from old, update cover
      cover: 'cover${fileType.ext}',
      // ...other fields from old
    ));
  }
  // Evict image cache
  PaintingBinding.instance.imageCache.evict(...);
  return true;
}
```

需要处理：删除旧的 `cover.*` 文件（如果扩展名不同）。需要 import `detectFileType`。

void _openCoverLocation() async {
  if (widget.coverFilePath == null) return;
  final file = File(widget.coverFilePath!);
  if (!await file.exists()) {
    context.showMessage(message: "Cover file not found".tl);

}

## Part 2: P2-A 章节名格式化

### 2.1 新建章节标题解析器

**新文件**: `lib/foundation/chapter_title_parser.dart`

```dart
class ParsedChapterTitle {
  final int? chapterNumber;
  final String? scanlationGroup;
  final String rawTitle;

  const ParsedChapterTitle({
    this.chapterNumber,
    this.scanlationGroup,
    required this.rawTitle,
  });

  /// "第5话" if chapterNumber is 5, otherwise rawTitle.
  String get displayTitle {
    if (chapterNumber != null) return '第$chapterNumber话';
    return rawTitle;
  }
}

ParsedChapterTitle parseChapterTitle(String title) {
  // Pattern 1: "Ch.5 - Luna Toons" or "Chapter 5 - Group"
  // Pattern 2: "第5话" (already Chinese)
  // Pattern 3: "5" (pure number)
  // Pattern 4: "Ch.5" (no group)
  ...
}
```

正则模式（按优先级）：
1. `/(?:Ch\.|Chapter)\s*(\d+)\s*[-–—]\s*(.+)/i` → ch=$1, group=$2
2. `/第\s*(\d+)\s*话/` → ch=$1, group=null
3. `/^(\d+)$/` → ch=$1, group=null
4. `/(?:Ch\.|Chapter)\s*(\d+)/i` → ch=$1, group=null
5. fallback → ch=null, group=null, rawTitle=title

  for (final name in chapterNames)
