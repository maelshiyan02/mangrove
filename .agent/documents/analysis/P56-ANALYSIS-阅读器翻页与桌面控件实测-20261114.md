## 1. 结论先行

> ✅ **用户已拍板（2026-11-14）**：① 空格 = **0.5 × 视口 + 200 ms `Curves.ease`**；
> ② UI **照 comix 实测**（右上胶囊 + 居中模态章节列表；章末双卡常驻内容流）；
> ③ 下一步**按 OPENER §8 继续施工**。三项决策已固化，施工时以本节为准。

1. **comix.to 默认空格 = 瞬时跳 100% 视口（758 px），无动画**；站点设置里提供 `Scroll fast` / `Scroll smooth` 切换与步长百分比（默认 **100%**，可 −/+/Reset）。
2. **包子漫画空格 = 0.875 视口（663 px）、约 133 ms 的 ease-in-out 平滑滚动**（9 个变化帧，增量先增后减）。
3. 用户口述「幅度大概半页左右」与两站默认值**都不同**。因此 Mangrove 的空格步进与动画必须由用户拍板，不能直接照抄任一站点。建议 **0.5 视口 + 200 ms `Curves.ease`**（沿用现有连续模式动画参数，仅把步长从 `0.25` 提到 `0.5`）。
4. **两处与 OPENER 表述的语义差异**（§4）已确认按 comix 实测执行，OPENER 原话不作为实现依据。

## 4. 🔴 两处语义差异（施工前必须确认）

| # | OPENER 表述 | 实测事实 | 影响 |
|---|---|---|---|
| 1 | T5「章节树从左抽屉**移到右上角浮层**（comix.to 的章节下拉）」 | comix 右上角只有**胶囊入口**；点击后弹出的是**居中模态 + 全屏遮罩**的章节列表 | 若按"右上浮层"实现，会得到与 comix 不同的交互；需确认是「右上胶囊 + 居中弹窗」还是「右上锚定的下拉浮层」 |
| 2 | T4「滚动到章末时**弹出**两个按钮」 | comix 的两个按钮是**常驻在最后一页下方的内容流**，不是弹出/浮层；其后还有点赞与评论流 | 决定章末组件是 `Sliver` 内容节点还是 `Overlay`；另外「始终可达」的兜底（图片未加载完 / 只有一页 / 空章节）需要单独设计 |

> ✅ **处置（用户拍板）**：**照 comix 实测** —— 章节右上角只放胶囊入口，点击开「居中模态 + 全屏遮罩」的章节列表；
> 章末两按钮做最后一页下方的**常驻内容节点**（355×44 两张并排、间距 10），不做弹出浮层、不做角落浮动按钮。
