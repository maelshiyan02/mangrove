```

             └─ 右上角 [+ 添加服务商]  → 弹出「添加服务商」对话框
                 └─ 服务类型 (SegmentedButton) 三选一：
                    [ AI 模型 ]  [ 谷歌翻译（免 Key） ]  ★[ Custom script (JavaScript) ]
                       └─ 选第 3 项后 → 出现脚本编辑器：
                          · Script 文本框（14 行，默认填入 ScriptTranslator.template）
                          · [恢复模板]   · [测试脚本]
```

- 落点：`pages/settings/llm_providers_settings.dart`
  - `:517` `ButtonSegment(value: LlmProviderKind.script, label: "Custom script (JavaScript)")`
  - `:545` `else if (_kind == LlmProviderKind.script) ..._buildScriptFields()`
  - `:368` `_buildScriptFields()` / `:416` `_testScript()` / `:464` `_mockScriptClient()`
- **第二条入口**：漫画详情页在"未配置 LLM"时会弹「LLM provider not configured → 去设置」→ 直接开 `LlmProvidersPage`（`comic_details_page/actions.dart:196`）。

### 5.1 现状（读 `utils/import_comic.dart` / `file_type.dart` / `comic_metadata_resolver.dart`）

| 方向 | 支持格式 | 落点 |
|---|---|---|
| **导入** | `cbz / zip / 7z / cb7`、`.mangrove_comics`、目录（单本/多本自动判定）、EhViewer `.db`、本地下载目录扫描 | `ImportComic.{cbz, files, multipleCbz, directory, ehViewer, localDownloads, inspectFolder}` |
| **元数据** | `details.json` > `ComicInfo.xml` > `metadata.json`（含 BOM 剥离、SAF 兼容） | `comic_metadata_resolver.dart` |
| **导出** | `cbz`、`pdf`、`epub`、`.mangrove_comics` | `utils/{cbz,pdf,epub}.dart` + `translation_project/finished_export.dart` |

### 5.2 🔴 缺口：**单向，不是双向**

```
    图片 / 目录 / 压缩包 ──导出──▶  cbz / pdf / epub      ✅ 有
       pdf / epub ──────导入──▶  本地漫画               ❌ 无
```

- **无 PDF 导入**：`pubspec.yaml` 无 `pdfrx` / `pdfium_flutter`；`import_comic.dart` 白名单不含 pdf。⇒ "PDF 电子书 → 纯图片漫画"这条**完全没有**。
- **无其它电子书格式**（mobi / azw3 / epub→图）互转。
- 上游 v2.3.5 的对照项正是 **PDF 导入为本地漫画**（需 `pdfrx_engine` + `pdfium_flutter`，本地无）；`P10.10 §1.2` 已把它归入"按点摘取·需改造"。
- 上游的**大文件导出修复**已落地（`epub.dart`，见 §一②）；`pdf.dart` 仅残留一个**未被调用**的 `import zip_flutter`（无 `ZipFile/ZipEncoder` 使用），无空字节守卫问题。

> ⇒ 你要的"纯图片 ↔ PDF 双向"目前是**只出不进**；要补必须引 `pdfium`（原生依赖，非纯 Dart，需单独评估构建）。
