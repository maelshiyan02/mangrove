#### 三条底线（不能违反）

1. 🔴 **不能直接跑 `flutter`/`dart`**。构建只走托管 venv python：

   ```powershell
   & "$env:USERPROFILE\.workbuddy\binaries\python\envs\default\Scripts\python.exe" tools/run_build_task.py
   ```

   判据看 `builds/build.log` 出现 **`BUILD_OK`**；analyze error 看 `builds/step_2_analyze.log`。
   headless 只走 `…python.exe tools/run_headless_task.py <命令>`，输出在 `builds/headless.out`，
   **只认最后一行 `[CLI PRINT] verdict=success|error`**；SwapChain/EGL/HRESULT 0x887A0022 红字是无渲染表面噪音；
   退出码恒为 -532265403，不含成败信息。
2. 🔴 **本会话没有渲染表面**：图像解码/渲染/出图等像素操作**只能写 GUI 复测步骤交用户在登录会话验**；
   纯逻辑必须抽成**零 Flutter 依赖**模块（输入像素用合成 RgbaImage 夹具）做 headless 正反断言。
3. 🔴 任何「已完成 ✅」都必须有**反向验证**：注入故障后该断言必须真的 FAIL；
   **故障不能靠抛异常"变红"**（抛异常 = 装饰品断言）；空结果判 FAIL。

其他铁律：FT（BallonTranslator）工程 JSON 契约——下划线自有键**零字节 diff**、空表删键、未知键保留；
`Mangrove/assets/translation.json` 是 **CRLF**，新 i18n 必须走 `.tl`/`.tlParams`；
**不 git commit**（用户没让就不提交）；PowerShell 5 用 `;` 不用 `&&`；禁 cmd.exe；
末尾 PSSecurityException snapshot 是工具噪音。

     `<img class="rpage-page__img">`），而 `<img>` 探针只认 DOM。**整章页数组在 React 内存**。
     逆出**页对象字段 `bZ` = 完整图片 URL**（URL 构造器在重试计数 ≤0 时原样返回 `page.bZ`）。

     `_fetchPagesByDom` 改 **fiber 优先、`<img>` 探针次之**。
  2. 章节「只一页」根因 = 旧 DOM 翻页点完**只固定等 1.2s**，站方章节接口加密、SPA 先解密再渲染 ⇒
     误判「未生效」提前 break；且 `pagesHint` 取自**可见数字按钮最大值**（Next-only 时=1）⇒ 循环不进。
     → `_fetchChaptersByDom` 硬化：基准改**首页首行 href**、上界 →**200**、点击后**轮询最多 8s 等首行变化**、
     数字按钮缺失时点 **Next 兜底**（`_clickNextPageJs`）、总预算 100s。
  - **逻辑层反向验证**（Node 跑从 dart 正则抽出的**真实常量**）：正向 `bZ`×3→3 图 ✓ / 故障改名→0 图 ✓ /
