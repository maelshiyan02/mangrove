## 2. 修复（`Mangrove/lib/network/comix_client.dart`）

### 2.1 `urlOf`（核心修复）

```js
function urlOf(o){
  if(!o || typeof o!=='object') return null;
  var v = o.B0;                                   // 2026-10-12 线上构建：URL = B0
  if(typeof v==='string' && v.indexOf('http')===0) return v;
  v = o.bZ;                                       // 2026-10-11 构建：URL = bZ
  if(typeof v==='string' && v.indexOf('http')===0) return v;
  // 字段名随站方构建漂移（压缩名，会变）：页对象里**任一直接字符串属性**
  // 以 http 开头即认，并排除站点导航链接（/title/、/chapter），避免把章节
  // 列表 / 关联漫画数组误当页数组（harvest 取最长，撞上就全错了）。
  var ks = Object.keys(o);
  for(var i=0;i<ks.length;i++){
    var t = o[ks[i]];
    if(typeof t==='string' && t.indexOf('http')===0 &&
       t.indexOf('/title/')<0 && t.indexOf('/chapter')<0) return t;
  }
  return null;
}
```

- 旧实现 `bZ` + `q2` 守卫在新构建下**必然失效**；新实现**已知名优先**、**通用判据兜底**，
  下次再改名仍能命中。
- 排除导航链接：`harvest` 取**最长数组**胜出，若把「关联漫画/章节列表」误当页数组 ⇒ 全错，
  故必须以 `/title/`、`/chapter` 排除站点自身导航 URL。

### 2.2 文档注释同步

`_pagesByReactJs` 上方注释由「`bZ` 是完整图片 URL」改写为「**重试计数 ≤0 时原样返回页对象的完整 URL 字段**」，
并登记字段漂移对照（`tmq6ux-*` 的 `bZ`/`q2` ↔ `tmqy0z-*` 的 `B0`/`ka`/`Rh`/`MO`/`lk`/`NX`/`hs`）。

> 其余 P43 结构（`fiberOf`/`harvest`/`scan`/seeds、`_pagesViaReact` 20s 轮询、
> `_fetchPagesByDom` fiber 优先、`_fetchChaptersByDom` 首行基准/上界 200/轮询 8s/Next 兜底）
