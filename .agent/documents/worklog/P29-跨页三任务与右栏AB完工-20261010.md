## 2 · 四项功能落点

### B-2b 识别这一块
`_detectAcrossSeam`：nearestSeamToViewport → 双页 `decodeFullResolutionRgba` →
`buildSeamWindow`（超 2400 拒绝）→ `stitchSeamWindow`（异宽 null）→
**`TranslationWorker.instance.ocrPage(RgbaImage, …)` 直吃内存拼接图** →
`planSeamCandidates` → StatefulBuilder 勾选框（默认全选、OCR 文本对齐用 IntRect
四字段，因 IntRect 无值相等）→ 按顶页分组 captureBlockListEdit，每块
writeSpan + ensureBlockUid + sourceText，全程一个 CompoundEditCommand。

### B-3/B-4 建组 + 组面板
点选：建组模式用只读画布，片段点选自动回指真身；每新 uid 一个 captureBlockEdit
+ 一个 captureSeamReviewEdit(groupKey) 打包成**一个撤销步**。可视化：nest=并集框、
link=连线、8 色 hashCode 调色板、序号徽章、picked 琥珀虚框。组操作全部经
`_commitGroups` 写 `_groups`（空表删键）。翻译一次走 translateGroupOnce 包
TranslationDispatcher.translateBatch（一组恰好一次调用）。applyGroupAssignment
只设 translation，rich_text 由 owner 在同一撤销步补 syncFtRichText。

### B-5 跨页修图/复原/解跨页
`_repairSelectedBlock`/`_restoreOriginalSelectedBlock` 入口按 readSpan?.isCrossPage
分流。`_repairSpanBlock` 复刻单块两阶段（mask→union、mergeRepairedInpainted→
逐页 inpainted），统一逐页 rerender + ArtifactReconciliation。
`_restoreSpanParts(project, parts)` 是通用逐段盖回（intersect/subtract、全 0 mask
删文件），解跨页只传尾页 parts；`_dissolveSelectedSpanBlock` 尾页复原 + `_editBlock`
把真身矩形 xyxy 缩回 headRect + clearSpan。

### A-2 右栏
图标条 44px + 块/组/运行三 Tab + IndexedStack（sizing.expand）保活；折叠态用
Offstage，点图标只切 Tab 不展开；点画布块自动切块 Tab（折叠也只换 Tab）。
切出长画布自动关 span/group pick 并清草稿。

## 3 · 本轮抓出的四个真问题（都在断言层，不在功能层）

1. **P14 断言用 IntRect `==`**：IntRect（translation_types.dart）**无值相等**，
   `rect != IntRect(...)` 恒真 → 4 条新断言首跑绿路径就红（crossing 映射 /
   erase 摊平 / dissolve 头尾，功能实现本身全对）。修法：断言加 `_sameRect`
   四字段比较器。教训与"IntRect 对齐只能比四字段"同一条。
2. **异宽断言的故障路径没走注入函数**：`_invalidWidthRejected` 内部直接调了真
   `planSeamCandidates`，注入的"跳过 validateSpan"故障版被架空 → 故障路径仍绿
   （A02 装饰品）。修为命题全程走注入 fn，异宽夹具提为 `_realPlanBadWidth`。
3. **i18n 插值陷阱**：`'@a · ${x}'.tlParams(...)` 字面量里带插值 → 运行时先插值
   再查表，**永远查不到**；扫描器还把源码片段当缺失 key 报给 edit-check。
   规矩：`.tl` 字面量内只能出现 @占位，动态值一律走 tlParams。
4. **顺序契约扫描计数 2→4**：`wiring.result_still_renders_in_a_second_pass`
   要求 `await _rerenderResultPage(...)` 全文恰好 2 处且两两之间夹 inpainted 落盘；
   B-5 新增跨页修图/复原两处（均先写后画，复原的 inpainted 落在
   `_restoreSpanParts` 内、调用点在其后），计数改 4，注释更新为五处落点。

另：`restoreErasedPage` 返回 **Uint8List 像素**（不是 RgbaImage），多段连续盖回时
要逐次重新 `RgbaImage(w,h,bytes)` 包装再喂入。
