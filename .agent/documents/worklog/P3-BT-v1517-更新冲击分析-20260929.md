# BallonsTranslator v1.5.16 → v1.5.17 更新冲击分析

> 日期：2026-09-29
> 触发：开发者推送 1.5.17 更新，需评估对现有代码（含 VeneraX 融合层）的结构性冲击

## 三、逐项冲击评估

### 3.1 高风险项（需要验证）

#### ✅ G 键冲突 — 无冲击

| 维度 | 分析 |
|------|------|
| BT 更新 | 新增 G 键"移动选中文本框"，**主窗口作用域** |
| 我们的改动 | continuous_canvas.py 中 G 键通过 `WidgetWithChildrenShortcut` 注册，**长画布视口作用域** |
| 冲突判定 | **不冲突**——两者不在同一 widget 层级同时激活。长画布是独立的 `QGraphicsView`，注册的快捷键作用域限定在该视口上，不污染主窗口。退出长画布后 G 键自然回到 BT 原生主窗口 |
| 验证点 | 更新后进入长画布气泡修复模式，按 G 仍能进入框选；退出后在普通编辑模式按 G 能移动文本框 |

#### ⚠️ inpaint pipeline — 低冲击

| 维度 | 分析 |
|------|------|
| BT 更新 | 新增 Codex 图像修复 + 绘图工具独立选修复模型/覆盖提示词 |
| 我们的改动 | 未改过 BT inpaint pipeline；VeneraX 侧 `renderBtPage` 直接读 `imgtrans.json` 的 inpainted 底图，不调用 BT 修复管线 |
| 冲击判定 | **低冲击**——新增参数（修复模型选择、掩膜开关、提示词）不修改现有管线 API，只是在 UI 层增加选项。旧工程不加这些新参数也能正常工作 |
| 验证点 | 更新后运行原有翻译管线（扫描→校验→翻译→导出），确认 inpainted 底图正常产出 |

#### ⚠️ Bug 修复（拖放/全角渲染/页面切换）— 低冲击

| 维度 | 分析 |
|------|------|
| BT 更新 | 修复拖放后文本同步、全角字符中横渲染、切换页面崩溃 |
| 我们的改动 | continuous_canvas.py 涉及拖放和页面切换，但走的是长画布独立的页面管理逻辑，与标准 canvas 的拖放/切换是两套代码 |
| 冲击判定 | **低冲击**——bug 修复通常不改 API，且长画布的拖放/切换是独立实现。全角字符渲染改进可能间接受益 |
| 验证点 | 更新后在长画布中切换多页、拖放调整气泡位置，确认正常 |

### 3.2 无冲击项

| 更新项 | 理由 |
|--------|------|
| Codex 支持 | 新增账户体系和 LLM 调用，我们没改过 llm_* 模块 |
| 矩形/椭圆填充擦除 | 新增绘图工具，与翻译管线无关 |
| 字体搜索 | 改进字体匹配，我们没改过 font_registry |
| 翻译更新 | 仅 UI 文本，不影响功能逻辑 |

### 3.3 我们未实现但被覆盖的功能

| 功能 | 状态 | 更新是否触及 | 说明 |
|------|------|-------------|------|
| 虚拟长画布 | 未完成 | 是（Canvas bug 修复） | 长画布用了独立页面切换逻辑，更新可能修复通用 canvas 的切换崩溃，间接帮助长画布 |
| 对话框拼合 | 未完成 | 否 | 我们没实现任何拼合逻辑，更新也没提到 |
| 翻译管线优化（扫描/校验=二次翻译） | 完成 | 否 | 这是 VeneraX 侧的按钮语义重定义，BT 侧扫描/翻译管线未改 |
| 连续阅读加载速度优化 | 待优化 | 否 | 这是 VeneraX 阅读器的事 |

## 四、操作建议

### 更新前备份

```powershell
# 备份我们改过的 6 个文件（BT 源码在 Ballonstranslator_win_minium/）
cd d:\Ballonstranslator_Windows\Ballonstranslator_win_minium
git init  # 如果还没 git 追踪
git add ballontranslator/ui/continuous_canvas.py \
      ballontranslator/ui/mainwindow.py \
      ballontranslator/ui/webengine_browser.py \
      ballontranslator/ui/download_dialog.py \
      ballontranslator/utils/scraper/comix_client.py \
      ballontranslator/utils/scraper/__init__.py
git commit -m "Pre-BT-1.5.17-update backup: our modified files"
```

### 更新后验证清单

1. **启动 VeneraX 原有 BT 工程**：Error the Echo、其他翻译工程能正常扫描加载
2. **BT 翻译管线**：扫描→校验→翻译→导出，全流程通畅
3. **comix.to 下载**：从 comix.to 下载一本漫画，章节列表正常解析、图片下载 Referer 头正确
4. **G 键双模式**：长画布内按 G → 框选；退出后按 G → 移动文本框（BT 新功能）
5. **连续阅读**：VeneraX 阅读器连续翻阅多章不崩
6. **长画布基础功能**：拼接多章、翻页、返回编辑（未改代码但需确认更新没破坏）

### 如果更新覆盖了我们的代码

| 场景 | 处理 |
|------|------|
| comix_client.py 被更新覆盖 | 手动合并 Referer 头、软封禁检测、双通道切换代码 |
| mainwindow.py 被更新覆盖 | 手动合并 comix.to 菜单入口 |
| webengine_browser.py 被更新覆盖 | 手动合并 DOM 解析 + token 计算 |
| continuous_canvas.py 被更新覆盖 | 手动合并长画布逻辑（最复杂，备份先行） |

## 五、长期战略：翻译工作室化

BT 翻译功能整合到 VeneraX 变成"翻译工作室"的路线图中，本次更新的意义：

| 整合阶段 | BT 侧改动影响 | 本次更新冲击 |
|----------|--------------|-------------|
| P1 直读 BT 工程 | 无（纯 Dart 解析） | ✅ 安全，不涉及 BT Python |
| P2 封面/章节名 | 无（VeneraX 侧格式化） | ✅ 安全 |
| P3 翻译工作室（进行中） | 需桥接 BT Python 管线 | ⚠️ 本次更新的 Codex/绘图工具是增量增强，不修改翻译管线核心 |
| P4 下载迁移 | 需复用 comix_client | ⚠️ comix_client 若被更新覆盖需手动合并 |

**核心洞察**：BT 更新的增量方向（AI 图像修复、绘图工具增强）是与翻译管线平行的功能分支，**没有改动翻译/扫描/导出的核心管线**。这对整合工作非常有利——我们可以把翻译管线当作稳定后端来桥接。

## 六、总结

| 维度 | 结论 |
|------|------|
| **结构性冲击** | **无**。本次更新以新增功能和 bug 修复为主，没有破坏性 API 变更 |
| **风险等级** | 低 |
| **是否接受更新** | **是**，但更新前必须 git commit 备份 6 个改过的文件 |
| **更新后必验** | comix.to 下载链路、G 键双模式、BT 翻译管线通畅 |
| **长期影响** | 本次更新为增量增强，不阻碍翻译工作室整合 |
