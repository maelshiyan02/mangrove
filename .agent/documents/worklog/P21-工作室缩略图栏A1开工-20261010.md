## 2 · 5 条断言与反向验证（M08）

断言名（**不加** `blockOps.` 前缀）：`thumbrail.default_is_off`、
`thumbrail.gate_truth_table`（10 组含原因码）、`thumbrail.landscape_pages_are_hidden`
（横版/正方形隐藏、页号 1/3/5 不错位、尺寸 null 保留）、`thumbrail.tile_hides_edge_overlays`、
`pageheader.reads_png_and_jpeg_size`（PNG 1600×2400 / JPEG 800×600 / 截断 → null）。

每条都用 `_Probe(name, green, red, detail)` + `check(name, green && !red, ...)` 模式（`red` 抛异常视作判据失效）：

| 断言 | 故障路径（喂**不同实现**，检验**同一命题**） |
|---|---|
| `default_is_off` | 把声明替换成 `bool _thumbRail = true;` ⇒ 判据变红 |
| `gate_truth_table` | 红路径用漏判页数的实现 ⇒ 真值表不匹配 |
| `landscape_pages_are_hidden` | 红路径用 `>`（而非 `>=`）⇒ 正方形页不该隐藏却隐藏，判据变红 |
| `tile_hides_edge_overlays` | 源码切片构成性判据（缩略图模式下不得存在贴边覆盖层） |
| `reads_png_and_jpeg_size` | `_naiveProbe`（PNG 不做长度校验，缺字节当 0）⇒ 截断文件返回非 null，判据变红 |

夹具：`_pngFixture(w,h)`（33 字节 IHDR，CRC 填 0；解析器不校验 CRC）、
`_jpegFixture(w,h)`（SOI + SOF0）；截断夹具 = `Uint8List.sublistView(pngFull, 0, 23)`。

**实测**：5 条全部 `passed:true` 且「故障路径 = 变红」。全门禁见 §0。
