## 三、关键设计决策（与上游规格的差异与理由）

| 决策 | 选择 | 理由 |
|---|---|---|
| 数据源 | `context.reader.maxPage`（**不是** `totalPages`） | 🔴 `totalPages` 含章末评论页（`showChapterCommentsAtEnd` 时 +1），用它会多画一格死格。已在代码里写死并加注释 |
| 刷新通路 | 复用 `readerScaffold.update()` | 与底栏滑条**同一条**通知链（`images.dart:509 / 1237` 页变化时调用），不引入第二套进度状态 |
| 页格分隔 | **透明 `SizedBox`**，不画色 | comix 用 `border-bottom:1px solid var(--bg)` 刻出分隔。mangrove 阅读背景有 6 种可选，透明间隙自动透出当前背景，无需解析 `readerBackgroundColor` |
| 页轨上下边界 | `top/bottom` 随 `_isOpen` 动画，底栏可见时止于底栏上沿 | 避免遮挡底栏按钮、避免与底栏争命中。控件隐藏时铺满全高（对齐 comix `.rpage--chrome-hidden`） |
| 气泡定位 | 跟随**鼠标 Y**（`_pointerDy`）而非格中心 | 滚动模式下格中心要减滚动偏移、易错；跟随鼠标天然正确，长章节更精确 |
| visited 语义 | `maxVisited` 单调增长，仅章节切换时重置（key = `eid#chapter`） | 对齐 comix `.is-visited`：向后读全标记，向前回翻不清空 |
| 高密度章节 | 格高触 2dp 下限 → 轨道**内部滚动** + postFrame 对齐到当前页 | >400 页才触发。只在章节变化/首次对齐，避免用户手滚时被拉回 |
| 热区冲突 | **双保险**：段 `HitTestBehavior.opaque` + gesture 里 `railInset` 排除左缘 24dp | `isLeft` 同时供默认 30% 区与 `enableCustomTapZones` 两条路径读，改一处即覆盖两条 |
| 桌面限定 | `App.isDesktop`（非 web 的桌面） | 移动端左缘属系统返回手势；web 一并排除 |
