## 二、P1 功能说明（已实现，验收标准）

### 2.1 功能定义

让 VeneraX 阅读器直接打开 BallonsTranslator（BT）的 `imgtrans_*.json` 翻译工程：底图用 BT 的 inpainted 空白底图，译文从 json 的 TextBlock 读取并叠加渲染，不调用 VeneraX 自己的 OCR/翻译模型。BT 工程目录完全独立于 VeneraX 的 ComicLibrary，靠设置项指向，双向扫描互不干扰。

### 2.2 用户操作路径

1. 运行 `D:\Ballonstranslator_Windows\builds\venera\venera.exe`
2. 设置 → Data & Sync → “设置 BallonsTranslator 工程根目录” → 选择 BT 工作区根
   - 建议实测路径：`D:\Ballonstranslator_Windows\ComicLibrary\downloads`（内含真实工程 Error the Echo，194 页）
   - 同页另有“清除”按钮；该设置不同步（机器相关）
3. 本地漫画页出现第 5 个 tab **“翻译工程”** → 应扫描出 Error the Echo（标题=json 父目录名，副标题=祖父目录名）
4. 点开阅读验收：
   - 页面顺序按 json 的 `page_order`/`chapters`，不是文件名排序（真实工程有 `0/001.jpg` 与 `0/1.webp` 双键混排，靠磁盘存在性过滤）
   - 有译文的页：BT inpainted 底图 + 中文译文叠加
   - 无译文块或无 inpainted png 的页：自动回退显示原图（不应报错/黑屏）
   - 连续阅读模式同样要正常
5. 删除对话框验收：在“翻译工程”tab 删条目时，“Also remove files on disk”默认**不勾选**（防止误删 BT 工作区）
6. 详情页刷新按钮：对 BT 工程应触发重新扫描 json（不调生肉扫描器）
7. 改译验收（可选）：在 BT 里改译保存后回 VeneraX 刷新——image key 混入 json mtime，应自动显示新译文

## 三、已知限制（验收时如发现是这些，不算 bug；后续阶段候选）

1. **导出不带译文**：CBZ/PDF/EPUB/图片文件夹导出对 BT 漫画导出的是**原图**（导出走 `LocalManager.getImagesForComic`，未接 renderBtPage 渲染链）。若验收要求“BT 工程也能导出汉化成品”，这是下一步第一个候选改动点。
2. **渲染样式**：竖排靠宽高比+CJK 占比启发式判定；frgb/srgb 取自 BT 但 smart 模式文字色按底图亮度自适应（与 BT 原生排版可能有差异）；未读取 BT 的字体文件/描边/行距高级参数。
3. **无 inpainted 的页回退原图**（设计如此，不是错误）；BT intermediate 若存成 .jxl 则 Flutter 无法解码，同样回退原图。
4. 扫描为进入本地漫画页时触发 + 设置后手动触发；未做文件监听（改了 BT 工程需点刷新/重进页面，mtime 机制保证内容更新）。
5. 阅读器中 VeneraX 自带翻译开关对 BT 漫画不生效（设计如此，translationKey 恒 null）。
