# P30 · 用户 GUI 复测五问题修复（2026-10-10）

> 接续 P29。用户照《P29-GUI统一复测脚本》实测后提出 5 个问题。本轮全部完成代码修复，
> 像素/手感仍只能用户 GUI 复测（本环境无渲染表面）。

## 问题与根因

### 1. 文本块无法拖动（两处根因，叠加修复）

- **根因 A（真凶）**：`studio_page.dart` 的 `_projectBlocks` / `_canvasBlocks`
  给**本页自有块**也传了 `ownerPageKey: pageKey`。而 P28 的
  `hitTestMovableCanvasBlocks` 会跳过一切 `ownerPageKey != null` 的块
  （投影片段不可拖）⇒ 自有块被当成片段，**整块拖不动**。
  P29 交接时误把"组反查用的页键"与"投影片段标记"混用成了同一个参数。
- **修法**：`_toCanvasBlock` 新增独立可选参 `contextPageKey`（只用于
  `_tagOf`/`_isPicked` 的页反查），两处自有块调用改传它；`ownerPageKey`
  保持 null，片段语义不被污染。片段调用不变。
- **根因 B（手感）**：长画布里垂直 pan 归 ListView、单页里 InteractiveViewer
  也争用竞技场，普通 pan 经常赢不了。用户明说"长按"。
  `editable_text_block_canvas.dart` 新增 `onLongPressStart/MoveUpdate/End/Cancel`
  （长按 500ms 后识别器独占手势）；判定顺序与 `_onPanStart` 完全一致
  （先 resize 手柄后块、marquee 模式不触发）；长按 update 无 delta 字段，
  用相邻事件绝对位置差分后复用 `_onPanUpdate`/`_finishDrag`；
  `_fit`/`_natural` 每次 build 存好（长按回调在 LayoutBuilder 外触发）。

### 2. 缩略图按钮被横版首页误判置灰

- 龙女友第 1 页是横版宣传图，整本被误判成非上下翻页 ⇒ 单页模式下缩略图按钮
  变灰。用户拍板：**对所有漫画类别开放**，默认仍关，只是不再变灰。
- `thumb_rail.dart`：删 `ThumbRailGate.horizontalReading` 枚举与
  `thumbRailGate` 的 `direction` 参数/方向判定（剩 hasProject/stripMode/pageCount）。
- `studio_page.dart` 门控 getter 与 tooltip 同步去方向；
  `headless_p10_checks.dart` 真值表改 11 行（三种方向 single-page 全部期望
  ready），`_GateFn` typedef 去 direction。

### 3a. 长画布按页隐藏（验证横版首页与缺页的因果）

- 新纯逻辑件 `strip_hidden_pages.dart`：工程级下划线键 `_strip_hidden`
  = `{pageKey: true}`（复用 `SeamReviewEditCommand` map 快照，一个撤销步；
  空集删键；未知键保留；坏数据忽略不抛）；`readHiddenPages` /
  `writeHiddenPages` / `toggleHiddenPage` / `visiblePageIndices`（**原始下标**）/
  `nextVisibleAfterHide`（后可见优先→前可见→全隐 null）。
- `studio_scroll_canvas.dart`：State 新增 `_visible`（可见页原始下标），
  布局/几何/解码窗口/缝线全部只遍历它；itemCount/itemBuilder 改 `_visible`；
  didUpdateWidget 检测隐藏集变化 → 重建 + 下一帧 `_loadAround` + 吸附当前可见页。
- `studio_page.dart`：`_hiddenPages` 随工程读回；状态栏**页码右边的小方框**
  （✓ 显示 / ✗ 隐藏，两种视图模式都显示、都可点 —— 单页模式下横版图照常看，
  靠 ✗ 表达"它在长画布里被隐藏"）；`_toggleStripHidden` 走撤销栈
  （Ctrl+Z 后集合从 raw 重读）；隐藏当前页且在长画布时自动跳到下一张可见页。
- **联动是纯视图层**：隐藏页 item 不构建 ⇒ 其块/落在该页的跨页片段自然不画；
  `nearestSeamToViewport` 只含可见缝（建块/识别跨页选不到隐藏页）；
  **不删任何块/跨页/组数据**。

### 3b. 长画布 Ctrl + 滚轮缩放（50%~200%）

- `_stripZoom`（0.5~2.0，1.0=适配宽度），顶层 `Listener.onPointerSignal`
  识别 Ctrl+PointerScrollEvent（指数曲线压触控板大 delta）；
  Ctrl 按住时 ListView physics 临时换 `NeverScrollableScrollPhysics`
  （PointerSignal 不走竞技场，光靠 Listener 吞不掉滚动，必须双管齐下）。
- 布局：树结构**不随缩放变化**（P27 教训：ListView 重挂同帧双
  ScrollPosition 崩溃）—— 外层 `SizedBox(max(视口宽, 有效宽))` 恒常，
  <100% 由 Align 居中，>100% 由横向 SingleChildScrollView 左右滚；
  切档只改一个宽度数字。缩放中非 100% 时底部显示百分比浮标。
- `_spanPointerSignal` 同步：Ctrl 时不转发滚轮给条带。

### 4. 长画布显示隐患加固（随 3a/3b 一并排查）

日志佐证：`logs.txt` 中**没有** strip decode 失败/OOM 记录，"缺页"不是文件
解码失败，而是**估高漂移**（首页 0.68 横版比例让所有竖版页估高严重不足）
⇒ `_loadAround` 窗口中心与真实可见页错位、页被提前 dispose；旧的
`bool failed` 永久闩锁又让缺页"再也不好转"。修复：

- **逐页尺寸探测**：进长画布即 `_ensurePageSizes()`（只读文件头），
  `_pageHeight` 与缝几何未解码页优先用探测真值，全局长宽比只兜底；
  且全局 aspect **只从竖版页学习**（横版宣传页不再带偏 94 张竖版页）。
- **失败计数取代永久闩锁**：`int failures`，<3 次进窗自动重试，
  ≥3 次占位符显示「缺少页面图片，点击重试」（`retryPage` 清零重排队）；
  页离开窗口即"翻篇"（dispose 时 failures=0）。
- **解码并发上限** `maxConcurrentDecodes=3`（快速甩动不再把几十张全幅
  webp 同时压进解码管线 —— 对应用户实测十几页后崩溃的内存尖峰）；
  完成回调 `_pumpDecode` 补队；另加 `onError` 保证并发额度永不泄漏。

### 5. 右栏折叠/展开按钮去重（用户图 2）

- 旧：展开态 Tab 行有 3 Tab + 折叠钮，44px 窄栏同时有展开钮 + 3 个 rail 图标
  （重复）。新：**折叠/展开共用窄栏顶部一个位置**（chevron 随态翻向）；
  展开态窄栏只有折叠钮（3 个切换只在 Tab 行），折叠态放出展开钮 + 3 图标
  （点图标=展开并切 Tab，3 个切换只在窄栏）。IndexedStack + Offstage 保活不动。
