## 1 · 新增纯逻辑：`strip_geometry.dart`（条带几何，Flutter-free）

P25 的 `cross_page_block.dart` 只处理**虚拟坐标 ↔ per-page 子矩形**；而长画布上
拖出来的框用的是**第三种坐标**——"条带像素"（= 视口局部 + 滚动偏移，含每页的
居中留白与缩放）。两者之间需要一层换算，且必须与长画布**自己算页高的公式同源**
（`studio_scroll_canvas.dart:_pageHeight` 的 `min(1, 视口宽/页宽) * 页高`）。

| 能力 | 用途 |
|---|---|
| `StripGeometry.build` | 由页 key + 源尺寸 + 视口宽构造各页度量（渲染宽高 / 居中偏移 / 条带 top） |
| `seamStripYs` | 每一道缝（= 下一页页顶）的条带 y —— 缝线绘制用 |
| `nearestSeam(y, threshold)` | 离拖拽点最近、且在阈值内的缝 —— **缝线吸附/高亮**用 |
| `toPage(x, y)` | 条带坐标 →（页下标, 页内坐标），带居中偏移与缩放 |
| `splitStripRect(l,t,r,b)` | **按缝**把一个跨缝的条带矩形切成 per-page 子矩形（越页处夹住）—— **落盘 `_span` 的真相来源** |
| `bands()` | 各页 `PageBand`，供 `spanToVirtual` 使用 |

🔴 本文件**不含 Flutter 依赖**（只 import `IntRect` 与 `cross_page_block.dart`），
所以"拖框 → 切分 → 落盘"的坐标数学能在 headless 里被反向验证。

## 3 · 界面接线

### 3.1 `components/studio_scroll_canvas.dart` —— 条带级覆盖层

| 改动 | 说明 |
|---|---|
| 新参数 `spanMode` / `onSpanMarquee` | 一次性模式；盖住**整条**条带 |
| `Stack([listView, _spanOverlay(geometry)])` | 仅 `spanMode` 时叠加；**必须整条覆盖**——每页的 `EditableTextBlockCanvas` 手势被限制在单页内（D16 第②层），跨缝拖拽只能靠条带级手势层 |
| `Listener.onPointerSignal` 手动转发滚轮 | 覆盖层是 `HitTestBehavior.opaque`，会吃掉 `ListView` 的滚轮；否则"框选模式下滚不动" |
| `_toStrip(local)` = 局部 + `scrollOffset` | 锚点/当前点记在**条带坐标**（内容坐标），绘制再减偏移换算回视口 |
| `_SpanOverlayPainter` | 画**每一条缝**（视口外跳过）、**最近一条高亮**（2px）、**进行中的框**（填充 + 描边）；`shouldRepaint` 逐项比较 |
| `ListenableBuilder(listenable: _controller)` 只包住画笔 | 🔴 **滚动不触发本 widget 的 `build`**（只有跨页时父级才重建）⇒ 不订阅 `_controller` 时缝线会钉在屏幕上不动。订阅只重绘覆盖层，**不重建整条 ListView**。 |
| `_spanGeometry()` 的 `topPadding = pageGap * 1.5` | 🔴 起始偏移 = `ListView` 上下 padding(各 gap) + 每页自带 padding(gap/2) = **1.5·gap**。少算半个 gap 时（gap≠0）缝线会与真实页边界差半格、落盘块整体上移。gap 默认 0 ⇒ 平时恒等，但公式必须对。 |

## 4 · 设计取舍（写进代码注释）

1. **覆盖层而非改页内手势**：放宽 D16 只需在 UI 层加一层条带级手势，**不动块的数据结构**
   （块仍按页存，"跨页"只是同一逻辑块在顶页存 + `_span` 带各页子矩形）。
2. **`_spanMode` 与 `_marqueeMode` 互斥**：两者都靠"拖拽"，含义不同（页内建块 vs 跨缝建块），
   手势上无法共存，只能显式二选一。
3. **模式一次性 + 翻页复位**：与 P9.7 给 `_marqueeMode` 定的规则一致 —— 滚动翻页也算翻页。
4. **拒绝用 toast 不用模态框**：异宽是罕见且可解释的失败，`showToast`（`components/message.dart`，
   本仓库既有范式）比弹窗更轻。
5. **顶页承载块**：`parts.first` 是虚拟坐标里最上的一段，块落在它所在的页，`_span` 记全部段 ——
   这样"块的 `xyxy`"与"`_span.parts[0]`"始终一致，不会有两个几何真相。
