## ① 长画布缩到约 88% 必现「缺少页面图片」（+③排查）

### 根因（几何推演 + 日志双重定性）

- 全日志无 codec/read/null/threw 等真实解码失败；缺页页曾连续出现
  `decode start` → `decode canceled (left window)` → `decode stale (discard)`，
  最终滞留为非永久缺图占位。
- P31 的解码驻留窗口按**固定页数**（`windowRange` half=keepAlive~/2）计算，
  而 ListView 实际构建范围按「视口像素 + cacheExtent」计算。**缩小后页高变小**，
  cache 区构建出的页越过固定窗口下沿，边界页在窗口内外振荡，被反复 cancel/重开。
- **③结论：隐藏横版首页不是直接原因**。它只改 `_visible` 映射；顶满宽度是
  正确行为，保留。但隐藏后页几何变化会间接改变哪一页成为振荡边界。

### 修复

- `strip_decode_planner.dart` 新增纯函数 `planForViewport(...)`：
  - 紧带 `[scrollOffset-preloadPad, scrollOffset+viewportHeight+preloadPad]`
    与紧带相交的页进 `wanted`，也是开解候选；
  - 宽保活带用更大的 `retainPad`：紧带外宽带内的页**只保活**（不新开解、
    不 cancel、不 reset failures），用迟滞消除边界振荡；
  - 开解顺序按页中点到视口中点的像素距离；真正离开宽带才 evict/cancel/reset；
  - 原固定页数 `plan/windowRange` 保留，用于首帧未附着或 forcePos 场景。
- `studio_scroll_canvas.dart`：
  - 常量 `_stripCacheExtent = 250.0`、`_scrollbarGutter = 14.0`；
  - `_loadAround()` 有唯一 position 时走 `_planForViewport()`
    （preloadPad = viewportH+250，retainPad = viewportH*2.5+250），
    几何与 ListView top padding/item padding 同源（首页顶 gap*1.5、步进 pageHeight+gap）；
  - ListView 显式 `cacheExtent: _stripCacheExtent`，与解码紧带同源；
  - Ctrl+滚轮缩放：同一帧多个滚轮事件**只抓一次锚点**（`_zoomAnchor`），
    帧末按最终 zoom 一次 jumpTo 两轴并 `_loadAround()`，避免旧偏移互相覆盖。

- 新增共用纯函数 `image_translation/font_fit.dart::placeTextInBox(...)`：
  `dy = (boxH-textH)/2` 垂直恒居中；alignment 0/1/2 → left/center/right；

- 画布预览 `text_block_canvas.dart`：textAlign 映射修正为 0=left/2=right/
  默认 center；横排 fill/outline 都用 placeTextInBox 定位；竖排旋转空间内
  双向居中。
- result 出图 `page_renderer.dart`：横排 fill/stroke 改用 placeTextInBox
  （`alignment: style?.alignment ?? 1`、inset 2）；left/right 现在真正生效；
  竖排原本已双向居中，未动。
- 块面板 `studio_block_panel.dart`：无 format 时 SegmentedButton 高亮改 center。
- 🔴 `text_block.dart`：`FontFormat.defaultAlignment` 由 left 改 **center**
  （= FT 自身默认 = `createDefault` 写入值 = 面板高亮 = 双端绘制规则），
  旧工程无 fontformat 的老块回读也居中；未改 FT 契约/键名/写盘结构。
