## 1. 现状认知：三形态与各源（实测 `data/local.db` 13 条记录）

| 形态 | JSON | 谁在用 |
|---|---|---|
| grouped | `{"默認": {"230c97f8-…": "第01话"}}` | **拷贝漫画**（App v3 与网页 `comicdetail/<slug>/chapters`）；组内 key 是章节 UUID，话号只在标题 |
| versioned | `{"1 [copymanga]": [{title,key}]}` | **comix.to**（`70 [comix.to]`、`1 [Rokari Comics] [comix.to]`）；**P52 重建过的拷贝漫画本地记录** |
| flat | `{"0 [baozimh]": "第0话"}` | **包子 baozimh**；单版本源；comix.to 早期落库记录 |

⇒ 跨形态是**常态**，不是边缘情况。原来那句「模式不同不混并，保守保留本地」直接把「本地旧形态 + 源新形态」这类书判了死刑。

## 2. 修复

### 2.1 规范格（`_ChapterCell`）

```dart
typedef _ChapterCell = ({
  String bucketKey,   // 落盘用的原始桶键（版本化=外层话号键，其余=章节 key）
  String? numberKey,  // 归一话号，判断"同一话"用
  String? group,      // 归一翻译组（默認/默认/default → null）
  ComicChapterVersion version,
});
```

- `_cellNumberKey`：章节 key → **标题** → 外层桶键，依次回退。拷贝漫画 key 是 UUID（读不出话号），话号在「第01话」；P52 矩阵反过来（key 有码、版本 key 可能 UUID），所以三处都要试。
- `_normalizeChapterGroup`：`默認/默认/default` 视同无组，否则拷贝的「默認」和 comix 的 null 组同一话各占一格。

### 2.2 合并语义

`mergedWith` 新增跨形态分支：两边摊平 → 按「话号 + 组」去重（本地先入，源只补新身份）→ `_emitCells(union, matrixMode)`。

- **落回本地形态**：分组页签、下载目录名（`[语言] 话号 [组] [站]`）、阅读器下标全按本地形态算，换成源的形态会连累下游。
- **版本化新格子按归一话号落桶**：分组式源给的是 UUID，直接当外层键会让整本退化成字典序、新话排到最后。
- **扁平目标只认话号去重**：扁平没有组维度放第二格。
- 同模式分支（versioned×versioned / grouped×grouped / flat×flat）保持原逻辑，只把身份判定升级为「key → 标题 → 桶键」。

### 2.3 形态互转

`toVersioned()` / `toGrouped({defaultGroup})` / `toFlat()`，都走 `_canonicalCells → _emitCells`，已是对应形态时直接 `return this`（幂等）。

## 4. 踩坑

1. **`models.dart` 是 `part of 'comic_source.dart'`**：直接 `import '.../comic_source/models.dart'` 会报 `import_of_non_library`，必须 import 宿主库 `package:mangrove/foundation/comic_source/comic_source.dart`。
2. **wiring 断言别用注释里的字**：`_stripComments` 会把注释剥掉，把标记写在注释里必然 `green=false`；改用代码锚点（`_canonicalCells()` / `_emitCells(` / `final union = <_ChapterCell>[...mine];`）。
3. **注入点选错会连带红**：第一版 `union_drops_local` 注入成 `union = []`，结果 grows / keeps_shape / wiring 一起红（本地侧整段丢失 + wiring 读的正是这行字面量）。正确注入点是「并集的底」`mine = other._canonicalCells()`。
4. `analyze rc=1` 时真正的报错在 `builds/step_2_analyze.log`，不在 `builds/build.log`（wrapper 只记 rc）。
