## 1. 背景

项目从 `D:\Mangrove_Windows` 迁入工作区后，**四处绝对路径**同时失效：

| 位置 | 存什么 | 旧行为（失效后） |
|---|---|---|
| `%APPDATA%/…/local_path` | downloads 库根明文绝对路径 | 静默回落**空的默认目录** → 已下载漫画"全部消失" |
| `appdata.json settings.btProjectRoot` | projects 根（分号多根） | 扫描器 `root.exists()` 为假，整根跳过 |
| 每个工程 json 的 `directory` | 原图根绝对路径 | 回落到 json 父目录，原图全断 |
| `%APPDATA%/…/comic_source/` | 源脚本（本来就在 APPDATA） | 不随项目走 |

`local.db` 的 `comics.directory/cover` 是相对库根的（实测 5 行均为 `漫画名`/`cover.jpg`），
所以只换根、不用改库。

## 2. 实现

**便携根（portable root）**：`lib/foundation/path_roots.dart`（纯 Dart + dart:io，
无 Flutter binding，可被启动前 headless 自检引用）。从 `Platform.resolvedExecutable`
目录向上最多 6 级，找第一个满足签名的目录 P：① `P/mangrove.portable` 标志文件
（显式，最强）；② `P/ComicLibrary/downloads` 目录存在（隐式，项目树自带，零操作）。
深度覆盖部署态（上溯 2 级）与开发态（上溯 5 级）；找不到 → 全部维持旧行为。

**四处自愈规则**：

1. **库根**（`LocalManager.init`）：绝对路径在 → 原样（用户手动选的盘优先）；相对形式 →
   按便携根重放；绝对路径失效 → `P/ComicLibrary/downloads`（存在才采用）并**回写相对形式**
   `ComicLibrary/downloads`，下次搬家零自愈；都没有 → 平台默认（旧行为）。
   解析出的最终根注册到 `PathRoots.currentDownloadsRoot`（在任何 BT 扫描前）。
2. **btProjectRoot**（`BtProjectManager.roots` 静态 getter，所有消费方自动受益）：
   失效根重定位到 `P/ComicLibrary/projects`；相对条目按便携根重放；库在便携布局但
   设置为空时**自动补全**兄弟 projects 根。`persistPortableSelfHeal()` 在
   `App.initComponents` 末尾跑一次，回写相对形式。
   🔴 **无法重定位的失效根（移动硬盘没插）原样保留在设置里**，绝不抹掉。
3. **工程 json `directory`**（读侧 `TranslationProject.directory` 与 legacy
   `BtProject.parse`，两路同规则）：失效时取路径中最后一个 `downloads` 段之后的尾段
   （`<漫画>[/<章节>]`）拼当前库根，**拼出的路径必须真实存在**才采用。
   🔴 **读取绝不回写 json**（零字节 diff 契约，A03 §3.2）。
4. **漫画源**（`ComicSourceManager.doInit`）：合并扫描两个目录——
   `%APPDATA%/…/comic_source`（读写、更新/登录态，优先）与 `P/comic_source`
   （随项目走的只读副本；同名 key appdata 优先，便携副本不遮蔽用户更新版）；
   `.data` 读取在 appdata 缺失时回落便携目录，写仍写 appdata。

## 5. 构建坑（插件链接二次失效 · 第三次遇到）

迁移后 `windows/flutter/ephemeral/.plugin_symlinks/app_links` 是指向 pub cache 的
**SymbolicLink**，flutter build 重建时报 `PathNotFoundException errno=2`
（真符号链接需 SeCreateSymbolicLinkPrivilege，非提权会话没有；报错文案有误导性）。
修法：读 `.flutter-plugins-dependencies`（结构是 `plugins.<platform>[]`，PS 解析别当成
扁平数组），为全部 53 个插件用 **Junction**（不需特权）预建到 `.plugin_symlinks/<name>`；
删旧链用 `(Get-Item).Delete()`（只删 reparse point，不跟目标）。长效修法：开 Windows
开发者模式（需用户操作/提权，未擅自改）。详见 A14 §5。
