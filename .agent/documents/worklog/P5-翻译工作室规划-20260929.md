# 翻译工作室规划（BT → VeneraX 融合）

> 日期：2026-09-29
> 触发：BT v1.5.17 更新暴露 BT 源码更新成本过高，决定不再折腾 BT 侧，转向功能融入 VeneraX
> 命名：BallonsTranslator → **Fan Translation (FT)**，工程目录 BT → FT
> 前置：comix.to 漫画源配置分析（P4）

---

## 一、愿景

把 BT 的翻译管线能力融入 VeneraX，形成一个**翻译工作室**应用：

```
VeneraX（当前）
  ├── 漫画阅读器 ✅
  ├── 漫画下载（comix.to 等）🚧
  ├── 翻译工程（BT/FT 直读）✅
  └── 翻译工作室（新增）
        ├── OCR 🖼️ → 文本框
        ├── 翻译 📝 → 译文
        ├── 图像修复 🎨 → inpainted 底图
        ├── 气泡编辑 ✏️ → 框选/合并/移动
        └── 导出 📦 → CBZ/PDF/EPUB
```

**核心原则**：翻译管线（Python）留在 BT/FT 侧，VeneraX 负责 UI 和漫画管理，通过桥接层调用。

## 二、功能决策矩阵

### 2.1 保留并融入 VeneraX 的功能

| 功能 | BT 侧现状 | VeneraX 侧现状 | 融合方向 | 难度 |
|------|----------|---------------|---------|------|
| **BT/FT 工程直读** | imgtrans.json 输出 | ✅ `bt_project_manager.dart` 已实现 | 继续增强（page_order/chapters 降级） | 低 |
| **BT/FT 渲染链** | inpainted 底图 + smart 模式 | ✅ `reader_image.dart` 已实现 | 继续增强 | 低 |
| **comix.to 下载** | Python comix_client.py | 🚧 待开发（P4 规划） | Flutter 重写 + WebView | 高 |
| **多翻译组章节** | ChapterInfo.group | ✅ `ComicChapters.versioned` 已就位 | 补 UI 切换（P4 Phase 0） | 中 |
| **连续阅读** | — | ✅ 阅读器已实现 | 优化加载速度 | 低 |
| **翻译管线（扫描/校验）** | BT 核心功能 | 🚧 按钮语义已对齐（扫描=提取原文，校验=二次翻译） | **关键桥接点**：VeneraX → BT Python 管线 | 高 |

### 2.2 放弃/暂缓的 BT 侧功能

| 功能 | 原因 | 替代方案 |
|------|------|---------|
| **虚拟长画布** | 未完成 + BT 更新重写 canvas.py + G 键被 BT 改成移动文本框 | 阅读器连续阅读 + BT 原生 G 键移动文本框已够用 |
| **区域翻译（G 键框选气泡）** | 信号被 BT 删（region_translate_rect）、G 键被 BT 改 | BT 原生 G 键移动文本框已有；右下角区域翻译按钮继续用 |
| **comix.to Python 侧集成** | BT 更新抹掉 + 每次更新要手动合并 mainwindow.py | 迁到 VeneraX Flutter 侧（P4） |
| **proj_imgtrans.py 结构化输出** | BT 1.5.17 删除 page_order/chapters/workspace | VeneraX Dart 侧自行重建（已实现降级） |
| **长画布合并翻译对话框** | 依赖长画布 + 区域翻译，两者都放弃 | VeneraX 侧后续可以在阅读器里加跨页合并 |

### 2.3 不适合融合的 BT 新功能

| BT 1.5.17 新功能 | 评估 | 原因 |
|-----------------|------|------|
| **Codex API** | ❌ 不适合 | 闭源商业 API，调用成本高、隐私问题 |
| **图像生成** | ❌ 不适合 | 同样闭源 + 与翻译管线无关 |
| **shape fill（矩形/椭圆填充擦除）** | ⚠️ 可选 | 绘图增强，翻译工作室不需要，留给纯修图用户 |
| **TextItemMoveSession（G 键移文本框）** | ✅ 保留 | BT 原生功能，不冲突 |
| **TTY 中横渲染修复** | ✅ 受益 | 我们依赖它的文本渲染自然修复 |
| **韩语翻译/西里尔文字处理** | ✅ 受益 | comix.to 有韩漫，直接受益 |

## 三、翻译管线桥接方案

### 3.1 管线步骤

BT 翻译管线的核心步骤，每个步骤输出写入 imgtrans.json：

```
原图 → [扫描 OCR] → TextBlock(bbox, text)
                    ↓
        [校验（二次 OCR）] → 更新 text
                    ↓
        [翻译] → translated text
                    ↓
        [图像修复 inpaint] → inpainted 底图
                    ↓
        [导出] → CBZ/PDF/EPUB
```

### 3.2 桥接架构

| 层 | 技术 | 说明 |
|----|------|------|
| **UI 层** | Flutter (VeneraX) | 漫画管理、阅读器、翻译工作室界面 |
| **桥接层** | Python subprocess 调用 | `python -m ballontranslator.cli translate --project <path> --page <name>` |
| **管线层** | Python (BT) | OCR + 翻译 + inpaint，通过 CLI 暴露 |
| **数据层** | imgtrans.json | BT 和 VeneraX 的唯一数据契约 |

### 3.3 当前 BT CLI 能力

BT 目前没有正式 CLI，需要开发。但已有 headless 模式（`--headless`）可以复用。

### 3.4 备选方案

| 方案 | 说明 | 优劣 |
|------|------|------|
| A: Python subprocess | Flutter `Process.run()` 调用 BT CLI | 简单，但进程开销大 |
| B: Python isolate | `python_binding` 包直接调用 | 高效，但绑定复杂 |
| C: Dart 重写管线 | OCR 用 `tesseract` 或 LLM API | 彻底去 Python，但工作量极大 |

**推荐**：Phase 1 用方案 A（subprocess），稳定后评估方案 B。

## 四、FT 命名路线图

### 4.1 更名范围

| 位置 | 当前 | 目标 | 说明 |
|------|------|------|------|
| 项目名 | BallonsTranslator | **Fan Translation (FT)** | 正式名称 |
| 工程目录前缀 | BT | **FT** | `bt_` → `ft_`，`btProjectRoot` → `ftProjectRoot` |
| 类名 | BtProject, BtProjectManager | **FtProject, FtProjectManager** | 代码标识符 |
| 设置键 | `btProjectRoot` | `ftProjectRoot` | JSON key |
| 显示名 | 翻译工程 / BT | **翻译工作室 / FT** | UI 文本 |

### 4.2 兼容策略

| 场景 | 处理 |
|------|------|
| 旧 `bt_` 前缀的 LocalComic id | **保留识别** + 内部标记 legacy + 不自动迁移 |
| 旧 `btProjectRoot` 设置项 | 读旧键 + 写新键（或同时写新旧） |
| 旧 imgtrans.json | 无变化——它是 BT 输出，不关心我们叫什么 |
| 代码类名迁移 | 先用新类名做 wrapper（`FtProject extends BtProject`），逐步废弃旧名 |

## 六、风险与对策

| 风险 | 对策 |
|------|------|
| BT 再次更新时我们还要改 Python 源码 | **不再改 BT 核心源码**，只加 CLI 桥接层（独立文件，不碰 mainwindow/proj_imgtrans） |
| Python subprocess 性能不够 | 先用 A 方案，慢了再升级 B |
| BT 1.5.17 不再输出 page_order/chapters | VeneraX Dart 侧自行重建（已有降级） |
| comix.to token 签名变了 | Flutter WebView 直接渲染，让站点 JS 自己签 |
