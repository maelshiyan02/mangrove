## 1 · 🔴 D16 定位结论：「页面之间文本块互不侵犯」规则落在哪

计划书 §4-B2 要求"实现前先定位 D16"。用 Explore 子代理**只读搜索**后确认：

**这条约束不是一处显式 clamp，而是三层隐式保证叠加**：

| 层 | 落点 | 机制 |
|---|---|---|
| 数据结构 | 块**按页存储**（`TranslationProject.pages[pageKey]`） | 块矩形天然是页内坐标 |
| 交互作用域 | `studio_scroll_canvas.dart:458-485` 每页只传 `widget.blocksFor(page.key)` | 可编辑 canvas 的**块集合与手势**都只覆盖当前页 |
| 吸附参考线 | `block_resize_geometry.dart:339-356` `snapTargets` 把页边 `0 / pageWidth / pageHeight` 与其它块边一起纳入 | 拖拽/缩放**吸附到页边**（`editable_text_block_canvas.dart:339-357` 传入当前页尺寸） |

- `applyResize`（`block_resize_geometry.dart:125-177`）**只保证不反转/不塌陷，不 clamp 到页** ⇒ 页边界约束**只来自吸附**，不是硬限制。
- **没有任何一行显式拒绝"跨页块"**。

**对 B-2 的含义**：所谓"放宽成仅跨页块例外"，**不需要**改数据结构（块仍按页存，
跨页只是同一逻辑块在**头页**存 + `_span` 携带各页子矩形），也**不需要**拆掉吸附；
真正要改的是 **UI 层**——允许手势在缝处越界拖框、并把框按缝切分后落盘 `_span`。
⇒ 本轮先把 **L1 几何层**（互转/切分/校验）与 **缝窗口** 做成纯函数并冻结，UI 另起一轮。

## 3 · 5 条断言（`span.*`，全部含故障路径）

| 断言 | 命题 | 故障实现 |
|---|---|---|
| `span.split_maps_back_to_source_pixels` | §8.3 样例虚拟矩形 → 子矩形 → 并集**逐像素还原** | 切分时不减页内偏移 ⇒ 还原错位 |
| `span.window_is_bounded` | 正常比例 ≤ 封顶；**全幅拼接被拒**（null） | 无视封顶，全幅照样返回 |
| `span.never_writes_merged_image` | 整条流程（窗口→拼接→映射→切分落盘）后**目录字节不变** | 把合成图写进目录 |
| `span.rejects_mismatched_width` | 异宽判 `width_mismatch`；拼接异宽两页 ⇒ null | 不查同宽 |
| `span.parts_do_not_cross_page_bounds` | 越界/负坐标判 `part_out_of_page_bounds` | 不查越界 |

## 4 · 实现取舍（写成注释留在代码里）

1. **不设 `_isCrossPage` 标志位**：`parts.length > 1` 本身就等于"这是跨页块"
   （§8.3 结论 2，避免一个会和 `parts` 漂移的冗余字段）。
2. **缝窗口封顶 = 2400（一页高量级）**：正常 0.35 比例两条 ≈ 1680 < 2400；
   全幅（fraction=1.0）两条 = 4800 > 2400 ⇒ **拒绝**。超封顶**不静默缩**——
   否则"全幅拼接"会被悄悄放行，正是 §4-B2 要禁止的。
3. **`validateSpan` 四条规则**：非空 / 同宽（D12）/ 不越页 / 同页不重叠。缘由码
   常量导出，供 UI 显示原因。
4. **`_span` 与 `_uid` 都是惰性的**：单页块**根本没有** `_span` 键；跨页块的 `_uid`
   复用 P24 的 `ensureBlockUid`（块加入组/跨页块时才写）⇒ 零字节 diff 不受影响。
