## 1 · 接线内容

### 1.1 缝标记插在哪（`studio_page.dart` · `_buildPageRail`）

缩略图（thumb）分支不再直接 `ListView.builder(children)`，而是先算出**交错计划**
`plan`，再按它 builder：

- **只插在阅读序真正相邻的两张之间**（`indices[k-1] + 1 == indices[k]`）；
- 中间夹着**被隐藏的横版页**时（A-1.4/D11），那两条缝都是 `n/a`、永远不可检视
  ⇒ **不插标记**（也不占交互）。

`plan` 里元素是 `int`（缩略图在 `children` 里的位置）或 `SeamEntry`（缝标记），
仍是 `ListView.builder` ⇒ **没有**退化成一次性构造全部项（长章节页多时的关键）。

### 1.2 顶部计数条与跳转（D7）

`_buildSeamHeader()` 挂在列表之上：`Column[ Header, Expanded(ListView) ]`。

- 文案：`All page seams reviewed` / `@a page seam(s) to review`（`@a` = `toReview`）。
- 跳转按钮调 `_jumpToNextUnreviewedSeam()`：**从当前页的下边缘往后找并回绕**
  （连点几次是"一条一条往下走"，而不是每次跳回工程第一条）；当前页是末页时从
  末条缝起算 ⇒ 回绕到第一条。挑选逻辑仍是 P22 的纯函数 `nextUnreviewedIndex`。

### 1.3 标记动作走撤销栈

`_setSeamReview(seam, state?)` 用 P22 的 `captureSeamReviewEdit`（工程级可选映射快照）
包住 `project.setSeamReview` / `clearSeamReview`，再 `_history.push(command)` +
`setState(_revision++)`。⇒ 缝标记与块编辑**同一条路径**：可 Ctrl+Z、计入"未保存"。
`state == null`（清标记）落盘为**删掉该条**（维持"不存在即 nil"）。

## 2 · 两处实现取舍（都写成注释留在代码里）

1. **标记只插在相邻可见页之间**，所以 `_buildSeamMarker` 只会拿到
   `clean` / `split` / `todo` 三态 —— `n/a` 分支**删掉**了（原草稿里那条"极淡分隔线"
   是不可达代码：能插标记的两侧页必然都不是隐藏页）。
2. **弹出菜单类型参数是 `SeamState` 而不是 `String`**。
   原因：`edit-check` 的 P9 判据 `both_entry_points_use_the_same_widget`
   （`headless_p9_checks.dart:1084`）会**扫源码**，见到 `PopupMenuButton<String>(`
   就认定"又手搭了一个工程菜单"而判红。缝标记本就不是工程菜单，改用
   `PopupMenuButton<SeamState>` 既避开该启发式，也顺带去掉 UI 里的 wire 字符串往返
   （`todo` 即"清标记"）。
