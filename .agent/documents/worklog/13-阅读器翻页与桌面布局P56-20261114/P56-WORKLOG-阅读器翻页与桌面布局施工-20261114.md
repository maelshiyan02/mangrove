## 2. 定案与语义差异（沿用实测文档，不在本文改口径）

1. 空格 = **0.5 视口 / 200 ms `Curves.ease`**（方案 A）。原连续模式方向键为 `0.25 视口 / 200 ms ease`，本轮统一提到 `0.5`。
2. UI **照 comix 实测**：右上角只放章节胶囊入口，点击开**居中模态 + 全屏遮罩**章节列表；章末两按钮是**常驻内容节点**，不是弹出浮层。OPENER 里「右上浮层 / 弹出」原话不作为实现依据。
3. 桌面布局下 `←/→` 一律切章（不再服从阅读方向反转）；`↑/↓` 一律翻页。移动端布局返回 `none`，交回各模式原有映射。

## 5. 边界与已知取舍（不臆造）

1. **无缝连续模式（seamless）不插入章末双卡**：它会自动拼接下一话，插卡片会打断内容流；出口由右上胶囊 / 章节列表 / ←→ 提供。纯函数 `shouldShowChapterEndNavInFlow(seamless:true) = false` 有断言锁住。
2. **自动播放（auto page turning）到底仍跨章续播**：这是用户显式开启的定时翻页功能，不属于「拉动到边界就跳章」，本轮保留。
3. **桌面布局下三个旧 opt-in 开关不再决定控件显隐**（`readerChapterCapsule` / `readerShowZoomBar` / `readerProgressBarPosition`）：桌面控件统一由 `readerLayoutMode` 驱动；这些开关仍对移动端布局/非桌面平台生效。默认值**未改**，避免动到既有用户设置与依赖默认态的测试。
4. **桌面布局下的长按连续翻页**：由系统 KeyRepeat 事件逐次驱动（每个 repeat 一次半页），不再用 gallery 原有的 200/50 ms 定时器；移动端布局的长按重复逻辑原样保留。
5. **GUI 像素/手感验收**本会话做不了（A01 §3：`No Impeller context`，headless 输出里的 `HRESULT 0x887A0022` 是环境噪音、不是本次改动失败）。

### 10.4 GUI 像素验收的硬约束（重要，别再重试同一条路）
