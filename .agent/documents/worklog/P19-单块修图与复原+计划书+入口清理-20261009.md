## 任务二 · 单块级「修图」与「复原原图」

### 2.1 核心设计决策

**整页 vs 单块**：P18 把修图拆成第四段（整页批量），本轮加**单块粒度**。两者不冲突：
- 整页修图（第四段）= 批量补脏页产物
- 单块修图（任务二）= 点某块 → 只修这一块覆盖区域的字

**复原时掩膜必须外扩 ≥30%**（来自 BallonTranslator 实操经验）：
- inpaint 算法的实际影响范围比字形大
- 按字形级掩膜复原会残留一圈糊边
- 外扩 30% = 宁可多盖一点（多盖的是原图，一模一样）也不能留糊边

**为什么不直接改 `_regenerateResults`**：它是整页修图路径，块级修图在它旁边开辟新路径，互不干扰。

### 2.2 新增的算法层（mask_producer.dart）

**`buildRestorationMask(RgbaImage image, IntRect blockRect, {double dilation = 1.3}) → Uint8List`**（~40 行，纯 Dart）：

```dart
// 默认外扩 30%（四边各扩 15%，总宽高各乘 1.3）
final dilated = IntRect(
  max(0, blockRect.left - blockRect.width * 0.15).toInt(),
  max(0, blockRect.top - blockRect.height * 0.15).toInt(),
  min(image.width, blockRect.right + blockRect.width * 0.15).toInt(),
  min(image.height, blockRect.bottom + blockRect.height * 0.15).toInt(),
);
// 手动 clamp，不信任 computeMask 的窗口 clamp
// （越界写入会静默截断 Uint8List，但我们要准确的尺寸）
return buildMaskPage(image, [dilated]);
```

文档注释解释了三个为什么：
1. 为什么要外扩（inpaint 影响范围比字形大）
2. 为什么手动 clamp（不信任 computeMask）
3. 为什么默认 1.3（BallonTranslator 经验值，不是随意数字）

### 2.3 Headless 断言（headless_p7_checks.dart，新增 3 条）

| 断言 | 验证什么 | 故障路径 |
|---|---|---|
| `restore.mask_dilates_by_default_30_percent` | dilation=1.3 时，dilated 掩膜前景像素数 ≥ 原块 * 1.1 | dilation=1.0 没扩也被判成 ≥ 1.1 |
| `restore.mask_clamps_to_image_boundary` | 块紧贴左边缘外扩后，掩膜尺寸=整页 + 有前景像素 | 外扩越过边界后尺寸不对 |
| `restore.mask_polarity_is_255` | 前景像素值=255（不是 1 或反极性） | 极性反了 |

三条都带故障注入（M08 模式），block-ops-check 从 43 → 46。
