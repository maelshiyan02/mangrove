### 1.2 定位（用户 2026-10-08 明确）

- 【识别】= 原文框**左侧**，`Icons.text_fields`，tooltip「重新识别这一块」
- 【翻译】= 译文框**右侧**（`InputDecoration.suffixIcon`），`Icons.translate`，tooltip「重新翻译这一块」
- 🔴 **不做**建块自动识别；**不叫**"二次识别/二次翻译"；两个按钮**可反复点击**
- 图标全部 Flutter 内置 `Icons.*`，不引第三方字体图标

### 1.3 四个关键决定

1. **区域限定 OCR，不复用 `ocrPage`**。复用会三重出错：重检测全页（一次点击 = 94 页的活）、
   忽略点了哪个块、**重投语言票**（`ocrPage` 会统计全页投票锁语向，单块调它退化成"一块一票"）。
   所以 `ocrRegion` 的 `sourceLang` 由调用方传入。
2. **裁剪窗口先放大后夹取**，且放大量取整数（`~/ 2`）。先夹后放会让贴边块拿到偏心窗口；
   `(minSide - w) / 2` 在奇数差时是 `.5`，两侧各差一像素。
3. **识别结果坐标必须换算回页坐标**（`toPageCoords`）。写窗口内坐标会让文字挪到块左上角，界面不报错。
4. **三条写回拒绝**（`shouldApply`）：空结果 / 与现有译文逐字相同 / 与原文逐字相同。
   前两条各堵一个静默数据损失——空结果会抹掉用户手工校对好的译文；逐字相同是模型回声，
   写回去让人以为按钮生效了。第三条对**原文为空**的情况开了例外（用户手工清空原文、想让模型按位置猜一次）。

### 1.4 🔴 顺带修掉的两个真问题

| 问题 | 后果 |
|---|---|
| `sourceText` 只有 getter | 想写回识别结果只能写 `translation`。补 setter 时发现**不能**写拼接串：FT 的 `text` 是**列表**，塞字符串会让整块被当成**一行**，多行校对与自动换全失效，而读侧原样读回、界面看不出异常 |
| `_decode` 只返回 `RgbaImage` | 拿不到源宽 ⇒ 无法算 `scale`。新入口第一次做单块 OCR 就会在大页上裁错位置。改为一次解码返回 `(image, sourceWidth)` |

## 二、S-N3 · mask 生产 + 抹字复原

### 2.1 交付物

| 文件 | 内容 |
|---|---|
| `translation_project/gray_png.dart`（新） | **纯 Dart** 8-bit 灰度 PNG 编码器（IHDR + IDAT + IEND，CRC32 + `ZLibCodec`） |
| `translation_project/mask_producer.dart`（新） | `MaskPage`、`buildMaskPage`（字形级、逐 region **或**累积）、`restoreErasedPage`（抹字复原）、`maskCoverage` |
| `translation_project/result_renderer.dart` | 新增 `renderMaskPage` |
| `pages/translation_studio/studio_page.dart` | 两阶段保存的**第一阶段加入 `mask`**（与 `inpainted` 同批，两者互不依赖） |

### 2.2 🔴 为什么绕开 `dart:ui`

`ui.Image.toByteData` 需要 `ui.Image`，而拿到它只能走 `Picture.toImage` ——
本会话**没有渲染表面**（`A01 §3`），一调用就抛。那样 `mask/` 会永久处于
"写了但无法验证"的状态。手写 PNG 的代价是 CRC32 + zlib，两者都是纯 Dart
（`dart:io` / `dart:typed_data`），于是 **mask 生产第一次成为 headless 可测的产物**。

### 2.3 三个格式决定

| 项 | 值 | 依据 |
|---|---|---|
| 极性 | **255 = 已抹** | `patch_match.py` 把 mask 直接当 `PM_inpaint` 的洞；`drawing_commands.py` 用 `mask > 0` 判"这块被抹过"。反过来的极性会被每个读取方接受，却恰好修错像素 |
| 通道 | **PNG colour type 0**（单通道 8-bit 灰度） | 与 `cv2.imread(..., IMREAD_GRAYSCALE)` / `np.zeros((h,w), uint8)` 一致。改成 RGBA 也能读，但"单通道"就只剩约定 |
| 尺寸 | **整页**，不是逐 region 小窗口 | 待拍板 18 的结论；大页需要降采样时**不产出**（同 `inpainted` 的 `scale == 1.0` 谎言） |
| 行滤波 | filter type 0（None） | 写在磁盘一次、由外部工具（BT / OpenCV）读的地方不是耍聪明的地方 |

### 2.4 为什么是字形级而不是矩形

`mask/` 在 FT 里的角色是"哪些像素被抹了"。写成块外框会造出**同名但语义不同**的文件：
下游会拿它当字形级掩膜，把气泡里的整块背景也当成待修复区域 —— 抹得越狠越糊。
本项目最忌讳这种"静默分歧"，所以宁可慢一点也不走矩形近似。
（`A05 §4.5` 早就记下了这条，押后到今天才做，只因为纯 Dart PNG 让它**可验证**。）

### 2.5 抹字复原

`restoreErasedPage(original, inpainted, mask)`：把掩膜处的像素换回**原图**的值，
返回新 buffer（不改入参）。三条拒绝：尺寸不符 / mask 长度不符 / 全 0 掩膜（无可复原）。

🔴 **这不是 BT 的功能**。BT 只有单向的"抹"与它自己的撤销栈；它的 `erase` 分支
（`drawingpanel.py:915`）是把原图按 mask 混合回 inpaint 结果，而不是从 inpaint 结果
重建一张新底图 —— 用途不同（BT 复原"这一次误擦"，这里复原"整张底图退回未抹状态"）。
