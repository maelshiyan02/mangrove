## 一、RV 收尾（P33/P34 反向验证修漏）

### 1.1 `font.sfnt_rejects_garbage` 仍是装饰品

- **现象**：tZjvxk 批跑 12/13 检测到，`font_sfnt_accepts_garbage` 未检出。detail 写
  「5 junk bytes → null (rejected)」。
- **根因**：断言喂的 64 字节**纯随机垃圾**在 `system_fonts.dart:113` 的**魔数校验**
  处就 `return null`，根本到不了 116 行的 `if (tables == null) return null;` 守卫
  —— 而故障是注入在 116 行的。所以故障改了守卫行为，断言却测的是更早的路径，永远绿。
  （之前只改了注释、没改夹具的早退性质，误判为「已修」。）
- **修复**：把夹具改成「合法魔数 0x00010000 + numTables=0」的坏字节 —— 通过魔数
  校验（113 行不拦），但 `_readTableDirectory` 因 numTables=0 返回 null，正好落进
  116 行守卫。好代码返回 null（断言 PASS），注入故障后返回假字体记录（断言 FAIL）。
  同步把误导性的「5 junk bytes」诊断文案改成准确表述。
- **文件**：`Mangrove/lib/headless_p1_checks.dart`（17 号断言夹具 + 文案）。

### 1.2 两条 color 故障 OFF-TARGET BREAKAGE（结果被判不可靠）

- **现象**：`color_text_and_bg_swapped`、`color_flat_region_invents_a_colour` 各自
  连带打挂了本不该破的 color 断言，harness 标记「results unreliable」。
- **根因与修复**：
  - `color_text_and_bg_swapped`（交换 textRgb↔bgRgb）：凡是「读到的 textRgb 就是真
    字色」的断言都会红 —— 黑底白字、恒黑对拍、彩字保相三条都锁同一条 `textRgb`
    出口。这是故障的**真实必然后果**，不是测试设计缺陷。→ 补进 `EXPECTED_CASCADE`
    声明（诚实级联，而非判不可靠）。
  - `color_flat_region_invents_a_colour`：原故障把**整个函数**改成恒返灰，过度宽泛，
    连带打挂所有 color 断言。→ 改成只动「平涂区 → null」那一行（159 行
    `if (loN == 0 || hiN == 0) return null;`），双峰夹具（黑白/彩字）都不走这条分支，
    只破 `color.flat_region_returns_null` 一个断言（精确靶面）。
- **文件**：`tools/_reverse_verify.py`（故障定义 + `EXPECTED_CASCADE`）。

### 1.3 状态

- 三条被改动的故障已单独重跑（g7mKrD，**进行中**）：`font_sfnt_accepts_garbage` /

### 2.2 新脚本 `tools/forensics_download_sources.py`

整合取证 runner，取代散落的 `probe_copy_web*.py` 的「引导域扫描」角色，并补上 comix.to
**此前缺失的独立可达性探针**。

- **子命令**：
  - `copy` —— 拷贝漫画：① 解析 JS 的全部 bootstrap 域逐个探活；② 在首个存活 API 域
    上探 `/api/v3/system/network2` 域名自动发现；③ 本地校验签名头构造（HMAC-SHA256，
    **纯函数，无需网络**）。
  - `comix` —— comix.to：① DNS/TLS 可达性（证书有效性）；② 非浏览器客户端 GET
    （预期 403 = WAF 在位，200 = 意外需警惕）；③ WAF 挑战页关键字检测（与 App 端
    `looksLikeChallengePage` 同源关键字）；④ 打印 GUI 复测清单。
  - `all` / `sig`（仅本地签名校验）。
- **反漂移设计**：引导域 / secret 从 `venera-configs-main/copy_manga(6).js` **动态解析**
  （路径由脚本自身位置推导 + 支持 `MANGROVE_CONFIGS` 环境变量），不再硬编码，根除
  `mangrove-/venera-` 漂移。
- **无网络 / 无 requests 自动降级**：每个网络检查在缺 `requests` 或缺网时返回
  **SKIP + 原因**，**绝不输出假 PASS**（遵守项目「空结果判 FAIL / 不假绿」硬规矩）。
- **分工**：本脚本负责「引导域是否还活着 / 自愈接口是否还返数据 / 签名算法是否完好」；
  签名头「服务端是否仍接受」的权威验证由 `test_copy_v180.py`（QuickJS 跑真实 JS 对真实
  站点）完成，二者互补不重复。comix 的「轮换域 *.site 是否 403 / 哪条取图策略能过」只能
  在 GUI 用 `mangrove.exe --headless comix-spike` 测（需 WebView）。
- **沙箱冒烟测试**（无网络）：`sig` 真实跑通本地 HMAC 校验（PASS，已算出自洽签名）；
  `all` 网络项诚实 SKIP，零崩溃、零假绿。
