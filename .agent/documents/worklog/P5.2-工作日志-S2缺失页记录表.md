## 0. 本阶段目标

把"一张图失败 = 整任务失败、整章已下载文件被标记失败、失败位置不留痕"
改为：

- 单页失败**不再终止任务**，已下载的页保留（可用部分不丢）。
- 失败的页记入漫画根目录 `missing_pages.json`，重启后仍在（持久化）。
- 任务结束后显示"部分完成，缺 N 页"，而非 error。
- 全部成功时**不生成**记录表（无缺失不留下噪音）。
- 与既有续传兼容：成功补回某页 → 从表销账。

## 1. 改动文件

### 1.1 新增 `lib/foundation/missing_pages.dart`

缺失页记录表的读 / 写 / 增删 / 查询模块。

- `MissingPageEntry`：单条记录
  `{chapterId, chapterTitle, index, url, error, attempts, firstFailedAt, lastFailedAt}`。
  其中 `chapterId` = 章节目录名（`_chapterDirectoryName` 的结果；无章节漫画为 `''`），
  `index` = 页序号（文件名即 `{index}.{ext}`），`url` = 原图地址，供 S4 补救直取。
- `MissingPagesTable`：`upsert`（同 key 合并、累加 attempts、保留首失败时间）、
  `remove`、`countOfChapter`、`indexesOfChapter`、`chapterIds`。
- `MissingPages`（静态门面）：
  - 位置：漫画根目录 `missing_pages.json`（计划选项 A，全局可见、随目录走）。
  - **文件锁**：所有写操作经一条串行 Future 链，避免并发任务/补救互相覆盖。
  - **损坏兜底**：文件解析失败 → 重命名为 `*.corrupted-<ts>`，保留原数据供人工恢复，
    不静默覆盖；空表自动删文件。
  - `peek(dir)` 同步读取 + 内存缓存（供 S3 列表角标在 UI 线程调用）。
  - `save(dir, table)`：entries 为空 → 删文件；否则写盘。
  - `removeEntry(dir, chapterId, index)`：S4 补回某页后销账。

### 1.2 改 `lib/network/download.dart`

- 新增任务内状态：`_missing`（失败页列表）、`_recovered`（本次补回页集合）、
  `missingCount` / `isPartial` getter。
- `_ImageDownloadWrapper`：
  - 新增 `chapterId` / `isFinished`（= 成功 / 永久失败 / 取消）。
  - 重试次数改为常量 `ImagesDownloadTask._imageRetryLimit = 3`（与记录一致）。
  - **成功** → `task._onImageSucceeded(this)`（从 `_missing` 移出、进 `_recovered`）。
  - **用尽重试** → `error` 置位 + `task._onImageFailed(this)`（记表），不再让整章失败。
- `_downloadChapterPool`：
  - 不再因单页失败 `_setError` 终止任务；frontier 以 `isFinished` 推进，卡死的页
    不再阻塞整章。
  - 状态行实时附加 `缺 N 页`（下载页/本地页可见）。
- `_scheduleTasks`：失败页不再 `return`（停止后续调度），改为"已终结则计数跳过、继续"。
- 章节循环（多章 / 单章两路一致）：
  - 章末调用 `_flushMissing()` 写盘。
  - **保护**：若整章 0 页成功（`failed >= 总页数`）→ 视作源/网络整体故障，
    保留原 error 语义（`Failed to download images`，整章重试），不记为"全缺章"。
- `_flushMissing()`：加载磁盘表 → 销账 `_recovered` → `upsert` `_missing` → 写回。
  在每章末、`_setError` 前、任务完成前各调一次，确保即使中途被杀也不丢记录。
- `toJson` / `fromJson`：持久化 `_missing`，重启后下载列表仍能显示缺页数。

### 1.3 改 `assets/translation.json`

新增文案 key（zh_CN / zh_TW）：
`Failed to download images`、`@a pages missing`、`Completed, @a pages missing`。

## 2. 设计取舍（与计划对照）

- **整章全失败时保留 error 语义**：计划只说"一图失败不废整章"，未规定整章 0 成功。
  此处主动加保护，避免"源挂了却显示部分完成"掩盖真故障。
- **续传不自动重下缺页**：暂停/恢复时 `_index` 已越过失败页，缺页留待 S4 补救
  （符合"缺失信息已不再丢失，先靠人工/后自动化"的定调）。
- **记录表位置走 A**（漫画根目录）：已确认。

  无需同步 `assets/*.js` 到 APPDATA。
