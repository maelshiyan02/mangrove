## 三、关键设计决策

### R3-1 缩放簇

| 决策 | 选择 | 理由 |
|---|---|---|
| 步阶表 | gallery = 倍档 `[1.0, 1.5, 2.0, 2.5]`（相对本页 fit 缩放）；continuous = 绝对档 `[1.0, 1.25, 1.5, 2.0, 2.5]` | ⚠️ **偏离上游规格**：上游建议长卷 50/75/100/125/150%，但 continuous 的 PhotoView 是 `minScale:1.0, strictScale:true`，100% 以下根本到不了，硬加 50/75 只会得到两档死按钮。已记入 §7 遗留 |
| 上限 | `kMaxZoomRatio = 2.5`（与 continuous 现有 maxScale 一致） | 按钮不能缩放到双指捏不到的地方 |
| 缩放状态源 | 订阅 `PhotoViewController.outputStateStream` | 三向同步（按钮 / 双指 / Ctrl+滚轮）的唯一可靠通路：controller 是每页一个，gallery 翻页会换实例，故按**实例身份**重绑（不是判空） |
| 显隐 | `MouseRegion(opaque:false)` 铺满 + 2s `Timer` | `opaque:false` 让 hover 既上报给本层、又继续命中下面的阅读区 ⇒ 唤醒不偷手势。状态归 scaffold（唯一能看见全部 hover 的一层） |
| 位置 | `right:16, bottom:100` | 章节切换 FAB 在 `bottom:36`（约 56dp 高），100 起不与它重叠 |
| 桌面限定 | `App.isDesktop && 默认关` | 触控布局里没有它的位置；默认关使手势用户完全不受影响 |

### R3-2 章尾导航卡

| 决策 | 选择 | 理由 |
|---|---|---|
| 🔴 页面落点 | 把导航页**折进 `reader.totalPages`**（+1），**不是**追加到 `totalPages+1` | 追加会连锁改 `itemCount` 与「滑过末尾 → 下一话」的触发索引（以及 `reader.page` 会短暂越界）。折进后：`itemCount = totalPages + 2` **不变**、`onPageChanged` 两个边界判断**不变**、`isChapterCommentsPage` 语义不变（`totalImagePages+1`），只是最后一页从图片页变成导航页 |
| 与评论页共存 | 评论页开启时，卡片**叠在评论列表上方** | 「评论页与导航卡可同页上下排布」（上游 §4.3）。卡片在上：刚读完一章时「下一话」最要紧，而评论列表可能很长 |
| 预取 | `cache()` 与 `_cachePage()` 都跳过导航页 | 🔴 否则 `getPageImagesRange()` 算出越界区间 → `images.sublist` RangeError |
| 禁用手势 | `PhotoViewGalleryPageOptions.customChild(disableGestures: true)` | 卡片是按钮，双指缩放只会跟点击抢事件（与评论页同样处理） |
| enabled 判据 | `visibleChapterFrom(chapter, ±1) != null`，**不用** `isFirst/LastChapterOfGroup` | 后者在「下一话存在但在另一个分组」时也返回 true，会误置灰一个能跳的按钮；`toNextChapter()` 本身就走 `visibleChapterFrom` |
| continuous | 一律不插 | 无缝跨章不该被打断 |

### R3-3 帮助弹窗

| 决策 | 选择 | 理由 |
|---|---|---|
| 键位判定 | `event.character == '?'`，**不是**逻辑键 | `?` 在多数布局是 shift+slash，但部分布局有独立键；判 character 最稳 |
| 判定时机 | 在 `_imageViewController?.handleKeyEvent()` **之前** return | 否则 `?` 会再被翻页处理器吃一次 |
| F12 | 保持原样（KeyUp 触发全屏） | 帮助弹窗只在 KeyDown 判定，两者不冲突；弹窗里也列出 F12 |
| 音量键 | 未列入 | 上游说「音量键仅 Android 不显示」，本轮没有音量键绑定，故不写 |

**C. 人工验收（逐项）**

*R3-1 缩放簇*
1. 设置 → 阅读 → **Zoom controls** 打开（确认**仅桌面端出现**）
2. 动一下鼠标 → 右下簇淡入；停手 2s → 淡出；鼠标停在簇上 → 保持可见
3. 点 `[−] [+]`：gallery 显示 `1x → 1.5x → 2x → 2.5x`；continuous 显示 `100% → 125% …`
4. **三向同步**：双指捏合 / Ctrl+滚轮 缩放时，簇上的数字**实时跟着变**（这是订阅 outputStateStream 的意义）
5. `[适应宽度]` → 回到 fit（含平移复位）
6. 🔴 **缩放后跨章接续**：放大状态下滑到下一章，不应出现「缩放被异常复位」或「上一章残留缩放」
7. 簇不与章节切换 FAB 重叠；窄窗下不被切掉

*R3-2 章尾导航卡*
8. gallery 模式读到最后一页 → 再翻一页 → 出现两张卡（上一话 / 下一话，带标题+话号）
9. 点「下一话」→ 进下一话；点「上一话」→ 进上一话**最后一页**
10. **首话 / 末话**：对应卡片置灰且点不动
11. 开启章末评论页 → 卡片出现在评论列表**上方**，两者同页共存
12. 🔴 continuous 模式**不应出现**该页（无缝跨章不被打断）
13. 设置里关掉 `Chapter end navigation` → 章尾恢复为直接触发下一话

*R3-3 帮助弹窗*
14. 阅读器里按 `?` 与 `F1` → 弹出快捷键表；`F12` **仍然全屏**（不冲突）
15. 表内键位与实际行为逐条核对（方向键 / AD / WS / 空格 / Shift+方向 / Esc / F12 / 单击 / 双击 / 长按 / Ctrl+滚轮 / 跨轴收藏）
