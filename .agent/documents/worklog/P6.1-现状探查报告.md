## 3. json 结构 · 往返字节 diff

### 3.1 格式契约（实测）

```
file size = 289485 bytes ; sha256 = cd631ff6…
UTF-8 BOM            = False
strict utf-8 decode  = OK
non-ascii bytes      = 5102          → ensure_ascii=False
contains '\u' escape = False
newline count        = 0             → 单行紧凑，无尾随换行
has '", "' = True ; has '": ' = True → Python 默认分隔符 (', ', ': ')
```

### 3.2 字段全集（实测，共 110 个块）

**顶层 6 键**：`directory` / `pages` / `current_img` / `image_info` / `page_order` / `chapters`

**TextBlock：23 键**（计划表原写 22，**漏了 `language`**，本次修正）
`xyxy, lines, language, distance, angle, vec, norm, merged, text, translation, rich_text, _bounding_rect, src_is_vertical, _detected_font_size, det_model, label, region_mask, region_inpaint_dict, fontformat, text_alpha_mask, _detected_font_name, _detected_font_confidence, text_layout_version`

**FontFormat：32 键**（与计划表一致）
`font_family, font_size, frgb, underline, italic, alignment, vertical, standard_vertical_roman_alignment, font_weight, line_spacing, letter_spacing, ligature_common, ligature_discretionary, ligature_contextual, oldstyle_nums, shadow_radius, shadow_strength, shadow_color, shadow_offset, gradient_enabled, gradient_start_color, gradient_end_color, gradient_angle, gradient_size, _style_name, line_spacing_type, text_transform, text_effects, glyph_slant_angle, opacity, stroke_width, srgb`

**`image_info` 条目**（97）：`{finish_code: 15, width: 690, height: 1347, translation_target: "简体中文"}`

### 3.3 往返 diff：**byte-identical = True**

```
[ensure_ascii=False, default sep] identical=True  len=289485 (orig 289485)
[ensure_ascii=True,  default sep] identical=False len=294595
```

**这是好消息，也把 S6 的写入契约定死了**：Dart 侧只要满足下面 4 条，就能做到"读入→不改→写回→零字节 diff"：

| # | 契约 | Python 行为 | Dart 现状 / 风险 |
| --- | --- | --- | --- |
| 1 | **分隔符 `", "` 与 `": "`（键值间有空格）** | 默认如此 | 🔴 **`jsonEncode` 无空格** → 必须**自实现紧凑-带空格序列化器** |
| 2 | **`ensure_ascii=False`（中文原样）** | 原样 | ✅ `jsonEncode` 默认不转义非 ASCII |
| 3 | **浮点 `20.0` / `0.0` 保留 `.0`** | `20.0` | ⚠️ Dart 有 int/double 之分，`20.0.toString()="20.0"`（**需 S6 实机确认**；JS 会给 `20`，但 Dart 不是 JS） |
| 4 | **键序原样（含未知键、含幻影键）** | dict 保持插入序 | ✅ Dart Map 保序；但**模型不能丢弃未知键/多余页键** |

> 佐证（P5，JS 参照，说明"分隔符差异"这一类问题的真实存在）：
> ```
> JS  JSON.stringify : {"a":1,"b":[1,2],"s":"中国","f":20,"g":1.15,"n":166.02710622064097,"z":0}
> ```
> 注意 JS 把 `20.0`→`20`、`0.0`→`0`；Dart 因保留 double 语义，预期与 Python 一致——但**这是 S6 必须先验证的第一件事**。

### 3.4 🔴 幻影页键：97 个 `.jpg` 条目全是空壳

```
pages total = 194   ext = {'.webp': 97, '.jpg': 97}
jpg entries=97  nonempty=0
webp entries=97 nonempty=62
jpg keys sample = ['0/001.jpg', '0/002.jpg', ...]   ← 磁盘上不存在这些文件
webp keys sample= ['0/1.webp', '0/10.webp', ...]    ← 真实页
```

- `.jpg` 零填充键（`001.jpg`）在磁盘**没有对应文件**（章节目录只有 97 个 `.webp`），是历史命名残留。
- `page_order` / `image_info` 只含 97 个 `.webp` → 阅读器靠"文件存在性"过滤，**自动忽略幻影键**（`bt_project.dart:219-221`），所以显示层不受影响。
- ⚠️ **但写入层受影响**：若 S6 模型只保留"有效页"，写回就会**删掉这 97 个空键 → 字节 diff 非零**。→ **契约要求：未知/多余页键原样透传**（或整体走"有序 DOM 透传"策略）。

```jsonc

### 4.3 一处需 S6 明确的细节
