# P1 · 空本地漫画链路修复（单点打开直达详情页）

> 日期：2026-10-23 ｜ 关联：用户 2026-10-23 反馈「新建本地漫画后显示不可用、点不开详情页去加章节」
> 阶段：本地漫画手动管理（续）→ 本次是「空本地漫画被误判不可用」的链路打通
> 前序：P7-WORKLOG-自建加章删章与comix封禁-20261023.md（v2.8.7+251）

## 一、现象（用户截图 + 复现）

- 用「新建漫画」建一本本地漫画 → 库根 `ComicLibrary/downloads/<名>` 生成**空文件夹**。
- 卡片右上角蓝色「素材」标签 + 缩略图占位 + ⚠（疑似 notDownloaded 指示）。
- **单点卡片** → 弹出 "Comic Not Available / This comic has not been downloaded yet" 对话框，**进不去详情页**，自然也无法加章节。
- 右键菜单「添加章节 / 管理章节」其实能用（它们直接拿 `comic` 对象调对话框，不经过 status 分支），但用户心智上期望「点卡片进详情页去加章节」，链路断了。

## 二、根因（证据先行）

1. `lib/foundation/local.dart` `LocalComic.status` getter（约 L125-142）：
   ```dart
   final contents = dir.listSync();
   if (contents.isEmpty) return LocalComicStatus.notDownloaded;   // ← 空文件夹直接判未下载
   ```
   新建的空本地漫画 `downloadedChapters` 为空、目录为空 → `status == notDownloaded`。

2. `lib/pages/local_comics_page.dart` `onTap`（改造前）：
   ```dart
   } else if (comic.status == LocalComicStatus.notDownloaded) {
     _showNotDownloadedDialog(comic);   // ← 本地空漫画被这里截胡
   } else {
     context.to(() => ComicPage(...));
   }
   ```
   那段 `notDownloaded` 分支本来是给**有网络来源**的漫画准备的（"你还没从源站下下来"）；
   但本地漫画**根本没来源**，空文件夹是"可填充"状态而非"不可用"，不该走这个弹窗。

3. 多选菜单的 "View Detail"（L504）早已正确 `context.to(ComicPage(...))` —— 说明详情页本身能开空本地漫画，
   只是单点 onTap 被 status 分支拦截。详情页没有"空本地漫画不可用"的二次拦截。

## 三、修复

`lib/pages/local_comics_page.dart` `onTap` 路由顺序调整：在 `notDownloaded` 分支**之前**插入
`comic.comicType == ComicType.local` 的直达分支：

```dart
} else if (comic.comicType == ComicType.local) {
  // 本地漫画无网络来源：空文件夹是"可填充"状态，不是"未下载不可用"。
  // 新建的空本地漫画必须能直接进详情页去加章节 / 换封面，不能走
  // notDownloaded 那个 "has not been downloaded yet" 弹窗。
  context.to(() => ComicPage(id: comic.id, sourceKey: comic.sourceKey));
} else if (comic.status == LocalComicStatus.notDownloaded) {
  _showNotDownloadedDialog(comic);
} else {
  context.to(() => ComicPage(id: comic.id, sourceKey: comic.sourceKey));
}
```

- 仅改路由，**不动** `LocalComic.status` 语义（`status` 还被"未下载"筛选 tab、data_sync 清理等使用，改它波及面大，留给 Phase 3 统一处理空本地漫画语义）。
- `ComicType` 本文件已 import，无需补。

## 四、校验

- `flutter analyze lib/pages/local_comics_page.dart`：**0 error**。
  - 仅剩 3 处 pre-existing `unnecessary_cast` warning（行号因本次 +3 行偏移，非新增）。
- ⚠️ 沙盒无 GUI 渲染表面，**无法实机点按验证**详情页打开效果；逻辑上本地空漫画现恒走 `ComicPage`，与多选 View Detail 路径一致（后者已被用户验证可用）。实机回归需用户在 GUI 会话确认。

## 五、遇到的坑（命名归档）

- **坑 P1-1「空目录被 status 判 notDownloaded 导致无法进详情」**：`LocalComic.status` 对"本地漫画"与"有源漫画"共用同一套 notDownloaded 语义，本地空漫画被误伤。本次只在路由层绕过；**根因级修复在 Phase 3**（空本地漫画应视为合法可填充状态，卡片 ⚠ 不该出现）。
- **坑 P1-2「notDownloaded 弹窗对本地漫画是误用」**：该弹窗文案/动作（Import / Download from source）对本地漫画无意义，路由层按 `comicType == local` 短路即可，无需改弹窗本身。
