## 1. 这一轮在纠正什么

用户三点：

1. **中文版找不到不重要**，韩版原版封面补全就够——不必再为快看封面耗时间。
2. **`season` 和 `vol` 不是同一个标准**：韩漫按季（Season Finale）连载，日漫按单行本卷出，两者使用场景不同。
3. **黑幕男主的限时保姆要重查季数**，并指出第四张封面更像**节日贺图**；要求先搜清韩漫在哪些节日换贺图，确认后再改命名，**不要虚报**。

第 2、3 条直接推翻了 P18 的一个前提。P18 把 MangaDex 的 `volume` 字段当成"纸质单行本卷号"，据此给韩漫打了 `vol(N)`——这个归因是错的。

## 2. 查证结果（先说结论）

### 2.1 Kakao 的 `[단행본]` 是小说单行本，不是漫画单行本

`page.kakao.com` 作品页「연관 작품」里确实有：

- `버린 쓰레기는 다시 줍지 않는다 [단행본]`
- `흑막 남주의 시한부 유모입니다 [단행본]`

点进去 `<title>` 是 **`- 웹소설`**——那是**原著小说**的单行本（渣男 `1~6권`，保姆 `1~5권 (완결)` + 외전）。漫画本体在 Kakao 上**没有**单行本条目。

所以 MangaDex 上那些 `volume=1..5` 不是"漫画第 N 卷"，只是上传者的编号。**韩漫这一层的正确维度是季，不是卷。**

### 2.2 保姆一共几季：3 季

证据链（能落地的都落地了）：

| 项 | 值 | 来源 |
|---|---|---|
| 总话数 | 116 话（含 8 话番外），2024–2026 完结 | `manhwaindex.com` 作品页 |
| 漫画单行本 | **无**（`Volumes: —`） | 同上 + Kakao 只有 웹소설 단행본 |
| 5 张里几张是正篇 | **3 张** | 见下面的甄别 |
| 当前主封面 = 哪张 | 原 `vol(5)`（紫白花园/茶会） | 与 Kakao `og:image` 像素差 **0.1** |
| 第一季主封面 = 哪张 | 原 `vol(1)`（金色王座） | MangaDex `createdAt` 2024-06-04，标注 `From Kakao`，贴着开播时间 |

116 话 / 3 季 ≈ 39 话一季，符合韩国网漫短季的节奏。三张正篇封面都是 **720×1030**（与 Kakao 官方导出规格一致），另外两张尺寸不同（839×1200、720×1008），是另外渠道的活动图。

### 2.3 哪两张是贺图

| 文件 | 画面 | 判定 | 依据 |
|---|---|---|---|
| 原 `vol(4)` | 韩服、柿子树、满月、**月兔**、韩屋窗棂 | **秋夕（추석）贺图** | 月兔是秋夕专属符号，春节没有；柿子也是秋夕代表果物 |
| 原 `vol(3)` | 满屏樱花、标题换成粉红渐变手写体 | **樱花季贺图** | 正篇标题是统一的金色立体字，这张整套换掉了；樱花＝4 月春季 |
| 原 `vol(2)` | 百合花、水面、女主闭眼 | 正篇（S2） | Logo 与 v1 同款、同规格 720×1030 |

**没有**把 `vol(3)` 写成 `event(april-fools)`：樱花季是 4 月，和愚人节同月但不等同，无法确认是不是愚人节活动换的，所以按**画面事实**命名。

## 3. 代码改动

### 3.1 新增 `coverEventOf()` / `coverBadgeOf()`

`Mangrove/lib/foundation/chapter_directory.dart`

- `coverEventOf(fileName)`：`[KR][cover]event(chuseok).jpg` → `chuseok`。认 `event(...)` / `event x` / `event=x`。
- `coverBadgeOf(fileName)`：给封面选择器的网格卡片出短标签——`第3季 · 韩`、`贺图 · 秋夕 · 韩`。文件名 `[KR][cover]event(cherry-blossom).jpg` 塞进卡片只能显示成 `[KR][cover]e…`，看不出是贺图。
- 三处注释重写：`season` 明确写"韩漫的季"，`vol` 明确写"日漫的单行本卷"，并注明**两者不是同一条时间轴**。

### 3.2 排序：贺图整体排到正篇之后

`coverVersionOf()` 对 `event(...)` 返回 `null`（没有版本号），`_compareCover()` 里 null 一律排后。这样**默认封面永远不会被一张活动图顶掉**——P18 那种 `max(season, vol)` 的合并逻辑保留（只是为了排出"哪张最新"），但贺图不参与。

### 3.3 封面选择器显示语义标签

`cover_picker_dialog.dart` 网格下方从 `file.name` 改成 `coverBadgeOf(file.name) ?? file.name`，读不出写法的老文件退回文件名。

## 5. 技术记录（可复用）

### 5.1 KakaoPage 用爬虫 UA 能拿到 SSR

普通 UA 请求 `page.kakao.com/content/<id>` 只有 42KB 空壳（`og:title` 是站点名）。换 **Googlebot** 或 **facebookexternalhit** UA，立刻返回完整 SSR：

- `og:title` = 作品名
- 作品类型（`웹툰` / `웹소설`）
- `og:image` = 官方**当前**主视觉（720×1030）——这是判断"哪张是平台此刻在用的封面"的锚点
- 前 25 话目录 + 「연관 작품」（`[단행본]` 条目就是从这儿发现的）

`content/<id>` 的来源：MangaDex 条目的 `links.raw`。

### 5.2 像素比对定锚

把候选封面与 Kakao `og:image` 缩到 64×64 灰度算平均差：

| 候选 | 与 Kakao 当前主封面 | 判定 |
|---|---|---|
| 原 `vol(5)` | **0.1** | 同一张 → 最新季 |
| 原 `vol(1)` | 65.2 | 不同 → 历史季 |
| 原 `vol(3)`（樱花） | 70.8 | 不同 → 活动图 |
| 原 `vol(4)`（秋夕） | 71.6 | 不同 → 活动图 |

同时与**小说**单行本封面比对，5 张差异全部 >77，**排除**"这 5 张里混了小说封面"的可能。

- 快看正版竖版封面：`imgCover` 无 src、签名接口、og:image 是横版，三条路都堵死。用户已说不重要，停。
