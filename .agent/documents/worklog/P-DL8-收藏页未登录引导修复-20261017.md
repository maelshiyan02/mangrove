# P-DL8 收藏页「Not login」未登录引导修复（2026-10-17）

## 1. 背景 / 用户反馈
用户在收藏页**网络区域**看到某源（包子漫画）报 `Not login` 错误，怀疑与 `comix.to` 站点连接变化有关，要求先取证诊断、再提方案、决策后修复、构建验证、最后入库记录。

## 2. 根因分析（与 comix.to 无关，是框架级登录拦截 + UI 缺引导）

| # | 证据 | 结论 |
|---|---|---|
| 1 | 全库唯一 `"Not login"` 抛点：`parser.dart:876` `retryZone` | 收藏加载前先查 `source.isLogged`，**未登录不发任何请求**直接 `Res.error("Not login")` |
| 2 | `isLogged = data["account"] != null`（`comic_source.dart:587`） | 登录态只看 `baozi.data` 里有没有 `account` 键 |
| 3 | `data/comic_source/baozi.data` 与**旧 C 盘原件**均只有 `settings`/`good_web_domain`，**都无 `account`** | 不是 P-DL7 迁移丢数据——包子源**从来没登录过** |
| 4 | curl 实测：`POST /api/bui/signin`→400(接口在)、`GET /user/my_bookshelf`→302(未登录重定向)、`cn.cnbzmg.com`→403(WAF gatekeeper，记忆已知) | 站点存活、登录/收藏接口都在；`my_bookshelf` 本身就要登录才看得到 |
| 5 | `baozi.js` 域名簇 webmota/kukuc/twmanga/dinnerku 未变 | 无新域名迁移，与 comix.to 无交集 |
| 6 | 日志里 `comix_to: CloudflareException / webview timeout` | **另一回事**（历史记录封面走 comix 的 WAF 老问题），与本报错无关 |

> 取证说明：agent-browser 启动时卡在 Chromium 下载（6 分钟无输出，已中止），改用 `curl` 完成同等站点取证，结论不受影响。
> 病根一句话：收藏页网络区会对**所有实现了收藏功能的源**列项；包子源要求登录（`isLogged=false`→"Not login"），但错误页只有「重试/导出日志」，**没有任何“去登录”指引**——纯体验缺陷。

## 3. 修复方案（用户拍板前因 429 限流未选，按推荐项 A 执行）
- **A（采用）未登录引导页**：收藏页对未登录源显示「前往登录」引导面板，直达已有的登录页，登录返回后自动刷新；改动小、零网络层风险。
- B（未采用）：A + 源列表对未登录源加角标/灰置。
- C（未采用）：不改代码，用户手动去源管理登录。

## 4. 代码改动清单
- `lib/pages/comic_source_page.dart`：把私有 `_LoginPage` 提为**公开可复用 `LoginPage`**（补 `super.key`，消除公开 widget 的 lint info）；所有调用点同步改名。
- `lib/pages/favorites/favorites_page.dart`：新增 `import 'package:mangrove/pages/comic_source_page.dart';`（已核实无循环依赖）。
- `lib/pages/favorites/network_favorites_page.dart`：
  - 新增 `_LoginRequiredView`（图标 + “需要登录” + “该漫画源需要登录后才能查看收藏。” + “前往登录”按钮 → 跳转 `LoginPage` → 返回后 `onLoggedIn` 刷新）。
  - `_NormalFavoritePage.build`：源有 account 配置且未登录时，直接显示引导页而非 `ComicList`。
  - `_MultiFolderFavoritesPage`：loadFolders 报 Not login 时，错误分支改显示 `_LoginRequiredView`。
  - **安全性**：仅对 `source.account != null && !source.isLogged` 生效；无需登录的源 `account` 为 null，仍走原 `ComicList` 路径，**零误伤、零回归**。
- `assets/translation.json`：新增 3 键（zh_CN + zh_TW）：`Login required` / `This source requires login to view favorites.` / `Go to Login`。
