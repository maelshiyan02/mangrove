# D01 · 多 agent 工作区迁移记录（2026-10-07）

> 目的：把 `.workbuddy/` 与 `.trae/` 两套并行的 agent 目录**合并为一个共享真身 `.agent/`**，
> 并为将来接入更多 AI agent 铺路。
> 关联方法论：`.agent/kb/methodology/M07-多agent共享工作区.md`

---

## 1. 迁移前 → 迁移后

### 迁移前（两套平行目录，靠手工同步）

```
.workbuddy/{memory,documents,skills,specs}     ← 真实文件
.trae/{memory,documents,skills,specs}          ← 真实文件（与上面逐字节重复）
docs/                                          ← 项目根的 42 篇工作日志
```

实测：`.trae` 与 `.workbuddy` 的 `documents`(4) / `skills`(3) / `specs`(2) **全部逐字节相同** ——
即同一份内容存了两份，靠"写完一边再拷另一边"维持。这正是 `M03` 里的静默分歧高危形态。

### 迁移后（一个真身 + N 个入口）

```
.agent/                        ← 🔴 唯一真身
├── README.md
├── memory/
│   ├── MEMORY.md              ← 主记忆（2005 字符，自动注入）
│   ├── appendices/            ← A01~A08 + W00（编号附录）
│   └── YYYY-MM-DD.md          ← 每日日志（保持在 memory 根，兼容各 agent 约定）
├── documents/
│   ├── worklog/               ← 原 docs/ 的 42 篇
│   ├── plans/                 ← 原 .trae/documents ∪ .workbuddy/documents（去重后 4 篇）
│   └── D01-多agent工作区迁移记录-20261007.md
├── skills/venera-windows-build/
├── specs/comic-translation-enhancements/
└── kb/                        ← 🆕 跨项目知识库
    ├── INDEX.md
    └── methodology/M01~M07

.workbuddy/{memory,documents,skills,specs}  → 目录联接 → .agent/*
.trae/{memory,documents,skills,specs}       → 目录联接 → .agent/*
docs/                                        → 目录联接 → .agent/documents/worklog
```

**9 条联接**（Windows junction，无需管理员权限）。

## 3. 备份与回滚

- 全量备份：`builds/_migration_backup_20261007/{workbuddy,trae,docs}`（76 个文件 / 1.6 MB）。

**回滚步骤**（如需退回迁移前状态）：

```powershell
$root = '<项目根>'
# 1) 删除 9 条联接（rmdir 只移除链接，不会删目标内容）
foreach ($p in '.workbuddy\memory','.workbuddy\documents','.workbuddy\skills','.workbuddy\specs',
               '.trae\memory','.trae\documents','.trae\skills','.trae\specs','docs') {
    cmd /c rmdir "$root\$p"
}
# 2) 从备份恢复三份真实目录
Copy-Item "$root\builds\_migration_backup_20261007\workbuddy" "$root\.workbuddy" -Recurse
Copy-Item "$root\builds\_migration_backup_20261007\trae"      "$root\.trae"      -Recurse
Copy-Item "$root\builds\_migration_backup_20261007\docs"      "$root\docs"       -Recurse
```

⚠️ **注意**：`.agent/` 里新增的内容（附录、kb、入口文件）**不在**回滚范围内 —— 回滚只恢复目录形态。

## 5. 遗留与注意

- ⚠️ **删除联接时不要用递归删除**（`rm -rf` / `Remove-Item -Recurse` 可能**跟随**联接删掉目标内容）→ 用 `cmd /c rmdir "<链接>"`。
- ⚠️ 若有工具会**删除并重建**自己的目录，联接会被打断 → 定期跑 `agent_links_check.py`。
- ⚠️ 备份工具可能**跟随联接**造成重复备份。
- 🟢 未来接入新 agent：建 junction + 写一个薄入口即可（见 `M07` 的检查清单）。
