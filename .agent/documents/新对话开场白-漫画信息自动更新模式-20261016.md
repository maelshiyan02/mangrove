## 三、本场任务：漫画信息采集/章节更新的自动/手动模式

### 需求（用户原话要点归纳）

1. **功能对象**：每次打开漫画都会自动进行的「漫画信息采集、章节内容更新」
   等相关功能——为本功能增加**自动/手动模式**。实现模式照抄 P-DL3 的
   缺页修复自动模式（appdata 默认键 + store 访问器 + 设置/漫画页双入口
   + 触发点挂钩）。
2. **设置新类别**：在「阅读设置」**下方**新增大栏「**漫画管理**」
   （设置左侧类别列表，用户截图已标位置：本地收藏那一栏的上方）。
   「漫画管理」设置区域下属的内容，就是漫画章节信息更新功能的模式选择
   （开关型：自动功能=设置打开/关闭）。
3. **网络/本地两套规则**：
   - 网络漫画：打开时**默认打开**自动刷新章节信息（最终设计）；
   - 本地漫画：**默认关闭**，只读本地记录的该漫画信息（本地模式）；
   - 🔴 **当前阶段先统一默认关**——用户原话：「由于后续我们还要开发网络
     漫画与本地漫画分离的双重规则，所以现在先暂时设置成关闭」。
     即：本场只做「一个总开关 + 模式判定框架」，两个规则都先默认关，
     等双重规则开发完再分网络默认开/本地默认关。
   - 后续演进方向：做成「更新按钮」（本场不做）。
4. **模式判定（按打开来源）**：
   - 主页「本地」库打开 → **本地模式**：不更新，只读本地记录的信息；
   - 搜索栏 / 收藏的「网络」打开 → **网络模式**：及时更新信息。
5. **漫画页加按钮**：与缺页修复一样，系统设置 + 漫画页都有入口。
