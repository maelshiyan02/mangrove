### 0. 这个项目怎么记东西（**先读这一节，它决定你后面所有动作**）

所有 agent **共用 `.agent/` 一个目录**，没有各 agent 的私有记忆：

```

    MEMORY.md              ← 唯一被自动注入的记忆（框架+索引+三条底线，≤3K 字符）
```

🔴 `.workbuddy/`、`.trae/` 下的 `{memory,documents,skills,specs}` 与 `<根>/docs`
**全部是指向 `.agent/` 的目录联接（junction）**。改任何一条路径都是改同一份文件，
**不存在"同步/拷回"这一步，也不要再做**。换 agent 后第一步先体检联接：

```powershell

```

🔴 **一切引用用相对路径**（`Mangrove/…`、`.agent/…`），**绝不写 `D:\…`/`C:\…`**——
项目根将来会改名。

#### 三条底线（不能违反）

1. 🔴 **不能直接跑 `flutter`/`dart`**。构建只走（WorkBuddy 托管 venv python）：

   ```powershell
   & "$env:USERPROFILE\.workbuddy\binaries\python\envs\default\Scripts\python.exe" tools/run_build_task.py
   ```

   判据看 `builds/build.log` 出现 **`BUILD_OK`**；analyze error 看 `builds/step_2_analyze.log`。
   headless 只走 `…python.exe tools/run_headless_task.py <命令>`，输出在 `builds/headless.out`，
   **只认最后一行 `[CLI PRINT] verdict=success`**；SwapChain/EGL/HRESULT 0x887A0022 红字是无渲染表面噪音；
   退出码恒为 -532265403，不含成败信息。
2. 🔴 **本会话没有渲染表面**：图像解码/渲染/出图等像素操作**只能写 GUI 复测步骤交用户在登录会话验**；
   纯逻辑必须抽成**零 Flutter 依赖**模块（输入像素用合成 RgbaImage 夹具）做 headless 正反断言。
3. 🔴 任何「已完成 ✅」都必须有**反向验证**：注入故障后该断言必须真的 FAIL；
   **故障不能靠抛异常"变红"**（抛异常 = 装饰品断言）；空结果判 FAIL。

其他铁律：FT（BallonTranslator）工程 JSON 契约——下划线自有键**零字节 diff**、空表删键、未知键保留；
`Mangrove/assets/translation.json` 是 **CRLF**，新 i18n 必须走 `.tl`/`.tlParams`；
真实工程夹具 = `ComicLibrary/projects/My Dragon Girlfriend Has Returned-1 [Asura Scans]/`
（PowerShell 路径含 `[` `]` 必须引号）；**不 git commit**（用户没让就不提交）。
PowerShell 5 用 `;` 不用 `&&`；禁 cmd.exe；末尾 PSSecurityException snapshot 是工具噪音。

### 2. 本轮任务（⑦字体/原图取色 + ⑧三下载源加强）

建议顺序：**先 ⑦a 后 ⑦b；⑧ 按"取证→适配→回归"逐站推进**。可以先与用户确认拆分与优先级。

#### 任务 ⑦a · 字体资产扩充 + 字号/行距等参数体验

1. 盘点现状：`bundled_fonts.dart` 注册族、4 个打包字体的 cmap 覆盖、块面板
   `studio_block_panel.dart` 现有控件（字号 6~120、行距、字距、粗细）。
2. 扩充字体资产（与用户确认要加哪些族；至少考虑：日文字种、繁体、竖排适用字体、
   若干装饰/强调字体）。每个新字体必须过 `tools/inspect_font.py` 的 cmap 覆盖自检，
   按 `A05 §3` 注册独立 family+别名+fallback，**绝不动 `primaryBundledFamily` 回退终点**。
3. 复核字号/行距/字距在双渲染路径的表现是否一致（`fitFontSizeCap` 用户值优先规则别动）。
4. 断言：字体注册/覆盖/回退做成纯 Dart headless 断言（参照 P9.6 字体批次的做法），
   全部带故障路径；视觉效果交 GUI 复测。

#### 任务 ⑦b · 译文颜色默认跟随原图文字颜色（难点，用户已知技术难度高）

目标：识别/OCR 阶段估计原图文字颜色，写进块的 `frgb`，使译文与原图观感一致；
用户仍可在块面板手动覆盖。

要求：

1. **先调研再动手**：读参考库 `Ballonstranslator_win_minium/` 是否已有取色实现
   （文字区域像素采样/主色提取），有就按它的口径移植，没有就自己设计并在日志里写明取舍。
2. **算法必须是零 Flutter 依赖的纯函数**（输入 RgbaImage + 块/行矩形，输出 RGB），
   用合成像素夹具在 headless 正反断言（如：黑底白字→白、白底黑字→黑；
   故障实现恒返回黑必须被打红；**不许靠抛异常变红**）。真实 webp 解码/管线接入的验证
   只能走 GUI 或 `pipeline-check`（本会话无渲染表面，见底线 2）。
3. 接好三个写入口径：OCR/识别建块、`TextBlock.fromOcr` 反向桥（在 `createDefault`
   之上 mutate，W39 教训）、旧工程兼容（无颜色信息时行为不变，仍黑字/用户显式值优先）。
4. FT 契约：颜色写 FT 的 `frgb` 键，不新增自有键；下划线自有键零字节 diff 不破。
5. 双端渲染一致：颜色透传走 `A05 §2` 的 RegionFontStyle 通道（填充+描边分支都要数）。
6. 块面板加颜色控件（若现只有值输入），支持"自动/手动"语义；i18n 走 `.tl` 且
   `translation.json` 保 CRLF。

#### 任务 ⑧ · 三个下载源针对性加强（逐站，不做一刀切抽象）

用户实测：包子漫画下一章**完全没速度**，疑因站点加了 Cloudflare 验证；拷贝漫画的
下载功能从未做适配迭代；只有 comix.to 做过几轮优化。方法论沿用 W04：
**网页取证 → 解析 → 取图 → 适配 → 回归验证**，每站单独一轮，别先抽公共层。

1. **先取证（每站都要）**：当前 JS 脚本版本、搜索/详情/取图 URL 链、失败点
   （DNS/TLS/403/503/Cloudflare 挑战页/签名过期）。用真实下载复现，留日志证据；
   网络注意 `A09`（外网/代理 127.0.0.1:7890；github 直连不通）。
2. **包子漫画**：重点判 Cloudflare 拦截层级——`network/cloudflare.dart` 现有能力是否够用、
   是否需要 WebView2 人工过挑战后取 cookie/`cf_clearance`（参考 comix 的 WebView 取字节
   路线 `A07`，但不要照搬 token 逻辑）。任何需要人工过盾的环节必须设计成**用户可见、
   可重试**，不能静默卡死（这就是"完全没速度"的体感来源之一）。
3. **拷贝漫画**：对照现行站点结构修 JS 源（域名轮换、签名/参数、图片 CDN 单次签名 URL
   过期等历史坑见 `A01 §2.2`），先跑通 `probe_copy_web*` 式取证再改。
4. **comix.to**：以现状为基线做回归（它是三站里唯一有原生客户端的），保证另两站改动
   不动公共下载件时它不退化；`download-check` 与 `comix-spike` 必跑。
5. 每站完成标准：真实章节可下载（速度/成功率留 GUI 实测数据）、失败有明确错误与重试/
   缺页补救路径（沿用 missing_pages + repair 机制）、headless 能验的解析逻辑必须抽纯函数
   +正反断言；JS 改完记得同步到 appdata `comic_source/`。
6. ⚠️ 若发现 Cloudflare 盾在当前环境无法无人值守通过，**停下来给用户选项**
   （手动过盾/换源/只读镜像），不要默默降级成假成功。
