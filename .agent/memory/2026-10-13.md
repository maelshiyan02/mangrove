- 项目搬入工作区后，本地已下载漫画全部检测不到。
- 四处绝对路径指向已不存在的 `D:\Mangrove_Windows\...`：
  - `%APPDATA%/…/local_path` = 旧 downloads 根 → init 静默回落空默认目录；
  - `appdata.json settings.btProjectRoot` = 旧 projects 根 → 扫描跳过；
  - 工程 json `directory`（每个工程内嵌的原图根绝对路径）；
  - 漫画源在 `%APPDATA%/…/comic_source`（本就不随项目走）。
