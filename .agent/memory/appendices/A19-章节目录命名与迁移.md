# A19 · 章节目录命名规范（D1）与命名迁移

> **触发时机**：改 `chapterDirectoryName` / 章节目录命名、写迁移/重命名脚本、
> 出现"图在磁盘上但读不到"、章节顺序乱、详情页编辑入口缺失时。
> **上级索引**：`MEMORY.md` §1
> **相关**：A17（comix 下载与假缺页）、A18（覆盖层与封面池）、A06（章节语义）

---

## 1. 命名规范（唯一真相 = `chapter_directory.dart`）

```
<话号> [<翻译组>] [<来源站点>]     49 [Rokari Comics] [comix.to]
<话号> [<来源站点>]                116 [comix.to]     （源没给组名）
<话号>                              119                （扁平章节，无组无站）
<n> [<组>] (2)                     同话同组重名，序号由矩阵唯一决定
<源 id>                            UUID / 整条 URL，**不可改名**
```

站点标签用**稳定网站名**，不用域名（域会漂移）：

```dart
_sourceSiteTags = {
  'comix_to': 'comix.to', 'baozi': 'baozimh',
  'copy_manga': 'copymanga', 'comick': 'comick', ...
}
```

Python 侧 `tools/library_migrate.py::SOURCE_TAGS` **必须与之逐条一致**，否则
同一本漫画在程序侧和脚本侧算出两个不同目录名。

---

## 2. 改命名规则的三条腿，缺一不可

| 层 | 落点 | 漏了会怎样 |
|---|---|---|
| 写入 | `ImagesDownloadTask._chapterDirectoryName` 传 `siteTag` | 新下的还是旧名 |
| 读取 | `getImagesForComic` → `resolveChapterDirectoryName` 语义匹配 | **下完读不到** |
| 反查 | `reconcileDownloadedChapters` 二级索引 | 磁盘有图但不登记"已下载"，显示未下载 |

### 语义匹配 `chapterDirectoryMatchScore`

- 话号相等、`(N)` 后缀相等
- 模板点名了组 → 候选必须同组；**组名不同一律拒绝**（否则两组图串）
- 站点标签有无都算命中（这正是要兼容的差异）

**不能用前缀匹配**：`5` 会同时命中 `5 [A]` 和 `5 [B]`。

### 缺页表连带

`missing_pages.json` 的 `chapterId` 就是目录名。新旧写法字面不等 → 红标消失。
所有读取点改用 `countOfChapterFuzzy`。

---

## 3. 哪些章节目录**绝对不能改名**

| 类型 | 判据 | 原因 |
|---|---|---|
| UUID 目录 | `parseChapterDirectoryName` 返回 null | 名字就是源 id，`chapterDirectoryName` 原样拿 key 当目录名；改名后语义匹配也救不了（模板没有数字可比） |
| 版本矩阵的 chapters 键 | value 是 `List` | 键是整条 URL / 源 id，改了切断源数据 |
| 分组结构的 chapters 键 | value 是 `Map` | 键是 UUID |

**只有扁平 `{目录名: 标题}` 才能改键**，判据：
`all(isinstance(v, str) for v in data.values())`。

---

## 4. 站点怎么确定（不许猜）

优先级：

1. `data/local.db` 的 `comic_type` → `data/implicitData.json` 的
   **`sourceTypeRegistry`**（`{hash: sourceKey}`，32 条，App 自己写的）
2. `local.db.source` 列（D1 之后新下载才会写）
3. 漫画目录里的 `chapters.json` / `_manifest.json` → comix.to
4. 子目录自带站标
5. 都不中 → **原样保留**，写进报告。**写错站名比不写更糟**

🚫 不能靠翻译组名猜站点：`[Asura Scans]` 既可能在 asuracomic.net，
也可能来自 comix.to 聚合。

## 5. 迁移脚本踩过的坑（`tools/library_migrate.py`）

| 坑 | 现象 | 修法 |
|---|---|---|
| **不幂等** | 跑两次 → `119 [baozimh] [baozimh]`（无点站标被当翻译组，又补一遍） | `KNOWN_SITE_TAGS` 显式收集；`build()` 组名==站标则去重 |
| **UUID 误判** | `2860aaf9-…` 被算成"第 2860 话" | 正则加 lookahead `(?=\s|\[|$)` |
| **只改盘不改库** | 扁平 chapters 键停在旧目录名 → 读不到 | `align_flat_chapter_keys`：拿库里的键去磁盘找，找不到按语义匹配回填 |
| **`\0` 是路径分隔符** | 封面 `116 [comix.to]\0.webp` 被拆成 `…` + `.webp` | `replace("\\","/")` 后按段拆；`0.webp` 的 `0` 是文件名 |
| **删封面顺序** | 先删后搬 → 唯一封面丢失 | 先搬/复制进池，确认池里有图再删根目录残留 |
| **封面来自章节内页** | 移走 = 缺页 | 用 `shutil.copy2` 复制 |

## 6. 章节排序

扁平章节（`ComicChapters(Map)`）**不排序**（const 构造），
`chapterDirectories.sort(a.name.compareTo)` 是纯字符串序 →
`1,2,3,4,48,49,5,6,7`。

修在**显示层** `ChapterOrderPrefs._orderedIndices`：用户自定义序优先，
其余按 `_compareChapterKeys`（前导数字比较）追加。
不动 `ComicChapters` 容器：`ids` 的原始顺序对翻页/下载也有意义。

## 7. 详情页编辑入口

```
本地模式 + 纯本地漫画 → showEditLocalComicInfoDialog（改 LocalComic 本体）
本地模式 + 网络漫画   → showComicOverrideDialog（写覆盖层）
网络模式              → 不给入口
```

⚠️ 改完必须 `refreshLocalComic()`，不能只 `update()`——后者只 setState，
`buildContent(context, data)` 拿到的还是旧 `data`（P10 原坑）。
