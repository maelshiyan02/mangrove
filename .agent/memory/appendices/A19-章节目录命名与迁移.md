# A19 · 章节目录命名规范（D1）与命名迁移

> **触发时机**：改 `chapterDirectoryName` / 章节目录命名、写迁移/重命名脚本、
> 出现"图在磁盘上但读不到"、章节顺序乱、详情页编辑入口缺失时。
> **上级索引**：`MEMORY.md` §1
> **相关**：A17（comix 下载与假缺页）、A18（覆盖层与封面池）、A06（章节语义）

---

## 1. 命名规范（唯一真相 = `chapter_directory.dart`）

```
[<语言>] <话号> [<翻译组>] [<来源站点>]   [zh-Hans] 49 [Rokari Comics] [comix.to]   ← P49 现行
[<语言>] <话号> [<来源站点>]             [zh-Hans] 120 [baozimh]
[<语言>] <话号>                          [en] 5
<话号> [<翻译组>] [<来源站点>]            49 [Rokari Comics] [comix.to]             ← D1 旧规范（仍可读）
<话号> [<来源站点>]                      116 [comix.to]     （源没给组名）
<话号>                                   119                （扁平章节，无组无站）
<n> [<组>] (2)                           同话同组重名，序号由矩阵唯一决定
<源 id>                                  UUID / 整条 URL，**不可改名**
```

**语言段在最前面**（P49，2026-10-27 定案）：语言是分类的第一维。理由——
同一话的简/繁/英/日版是**四份不同内容**，不是镜像；而 comix.to / mangadex /
comick 这类源**同一个站点同时供多种语言**，站点标签相同、话号相同，只靠
`[站点]` 区分必然撞车。简繁必须分开写 `zh-Hans` / `zh-Hant`（BCP 47 子标签），
不能写含糊的 `zh`。

站点标签用**稳定网站名**，不用域名（域会漂移）：

```dart
_sourceSiteTags = {
  'comix_to': 'comix.to', 'baozi': 'baozimh',
  'copy_manga': 'copymanga', 'comick': 'comick', ...
}
```

Python 侧 `tools/library_migrate.py::SOURCE_TAGS` **必须与之逐条一致**，否则
同一本漫画在程序侧和脚本侧算出两个不同目录名；P49 又多了
`tools/baozi_app_download.py::LANG_TAG` / `SITE_TAG` 与
`tools/migrate_chapter_languages.py::SITE_LANGUAGES` 两处，改语言默认值要四处一起改。

## 2. 改命名规则的三条腿，缺一不可

| 层 | 落点 | 漏了会怎样 |
|---|---|---|
| 写入 | `ImagesDownloadTask._chapterDirectoryName` 传 `siteTag` | 新下的还是旧名 |
| 读取 | `getImagesForComic` → `resolveChapterDirectoryName` 语义匹配 | **下完读不到** |
| 反查 | `reconcileDownloadedChapters` 二级索引 | 磁盘有图但不登记"已下载"，显示未下载 |

### 语义匹配 `chapterDirectoryMatchScore`

- 话号相等、`(N)` 后缀相等
- 模板点名了组 → 候选必须同组；**组名不同一律拒绝**（否则两组图串）
- 站点标签有无都算命中（这正是要兼容的差异）

**不能用前缀匹配**：`5` 会同时命中 `5 [A]` 和 `5 [B]`。

### 缺页表连带

`missing_pages.json` 的 `chapterId` 就是目录名。新旧写法字面不等 → 红标消失。
所有读取点改用 `countOfChapterFuzzy`。

---

## 3. 哪些章节目录**绝对不能改名**

| 类型 | 判据 | 原因 |
|---|---|---|
| UUID 目录 | `parseChapterDirectoryName` 返回 null | 名字就是源 id，`chapterDirectoryName` 原样拿 key 当目录名；改名后语义匹配也救不了（模板没有数字可比） |
| 版本矩阵的 chapters 键 | value 是 `List` | 键是整条 URL / 源 id，改了切断源数据 |
| 分组结构的 chapters 键 | value 是 `Map` | 键是 UUID |

**只有扁平 `{目录名: 标题}` 才能改键**，判据：
`all(isinstance(v, str) for v in data.values())`。

---

## 4. 站点怎么确定（不许猜）

优先级：

1. `data/local.db` 的 `comic_type` → `data/implicitData.json` 的
   **`sourceTypeRegistry`**（`{hash: sourceKey}`，32 条，App 自己写的）
2. `local.db.source` 列（D1 之后新下载才会写）
3. 漫画目录里的 `chapters.json` / `_manifest.json` → comix.to
4. 子目录自带站标
5. 都不中 → **原样保留**，写进报告。**写错站名比不写更糟**

🚫 不能靠翻译组名猜站点：`[Asura Scans]` 既可能在 asuracomic.net，
也可能来自 comix.to 聚合。

## 5. 迁移脚本踩过的坑（`tools/library_migrate.py`）

| 坑 | 现象 | 修法 |
|---|---|---|
| **不幂等** | 跑两次 → `119 [baozimh] [baozimh]`（无点站标被当翻译组，又补一遍） | `KNOWN_SITE_TAGS` 显式收集；`build()` 组名==站标则去重 |
| **UUID 误判** | `2860aaf9-…` 被算成"第 2860 话" | 正则加 lookahead `(?=\s|\[|$)` |
| **只改盘不改库** | 扁平 chapters 键停在旧目录名 → 读不到 | `align_flat_chapter_keys`：拿库里的键去磁盘找，找不到按语义匹配回填 |
| **`\0` 是路径分隔符** | 封面 `116 [comix.to]\0.webp` 被拆成 `…` + `.webp` | `replace("\\","/")` 后按段拆；`0.webp` 的 `0` 是文件名 |
| **删封面顺序** | 先删后搬 → 唯一封面丢失 | 先搬/复制进池，确认池里有图再删根目录残留 |
| **封面来自章节内页** | 移走 = 缺页 | 用 `shutil.copy2` 复制 |

## 6. 章节排序

扁平章节（`ComicChapters(Map)`）**不排序**（const 构造），
`chapterDirectories.sort(a.name.compareTo)` 是纯字符串序 →
`1,2,3,4,48,49,5,6,7`。

修在**显示层** `ChapterOrderPrefs._orderedIndices`：用户自定义序优先，
其余按 `_compareChapterKeys`（前导数字比较）追加。
不动 `ComicChapters` 容器：`ids` 的原始顺序对翻页/下载也有意义。

## 9. 语言维度（P49，2026-10-27）

### 9.1 为什么语言必须是第一维

复合漫画 = 一本书绑多个源、可能多个语种。此时：

- 包子源第 152 话（简体）= 一份内容
- comix.to 第 153 话（英化组）= 另一份内容
- 将来若加繁体 LINE 源，同一话号会有**第三份**

只靠 `[站点]` 区分不够，因为多语种共站的源站内就有多种语言。语言段放最前，
读者一眼看到"这一版是哪国话"。

### 9.2 语种从哪来（优先级）

1. `ComicChapterVersion.language`（mangadex / comick 章节自带 `lang`）——最准；
2. 源默认表 `_sourceDefaultLanguages`（`baozi`/`copy_manga`/`dm5`/`manhuaren`/
   `Komiic`/`mycomic`/`goda`/`zaimanhua`/`rumanhua` → `zh-Hans`）；
3. 都没有 → **不写语言段**，退回三件套旧名（宁可"未标注"，不许猜）。

⚠️ `comix_to` / `comick` / `manga_dex` 刻意**不登记**默认语种：它们是
多语种共站，凭源名猜会把英文版标成中文版，比不标更糟。

### 9.3 三条腿（和 §2 同理，缺一不可）

| 层 | 落点 |
|---|---|
| 写入 | `ImagesDownloadTask._chapterDirectoryName` 传 `languageTag` |
| 读取 | `parseChapterDirectoryName` 先 `splitChapterLanguageTag` 剥前缀再认话号 |
| 反查 | 同上（`chapterDisplayName` / `chapterNumberLabel` 也要剥，否则"不以数字开头"会被当成番外） |

判定辅助：`chapterDirectoryMatchScore` 只在**两边都标了语种且不同**时判不匹配；
只有一边标了（老目录没语言段）一律放行——那正是要兼容的差异。

### 9.4 改名时最容易踩的雷

- `local.db.comics.chapters` / `downloadedChapters` 里存的是**目录名**（早期扫描
  入库的记录，如 `"0 [baozimh]"`）。**改目录不改 DB = 磁盘有图却显示未下载。**
  网络漫画的 key 是源 id（`"0"`），映射不命中自然不动，安全。
- **有翻译工程的漫画不许改名**：`ComicLibrary/projects/<漫画> - <章节目录>` 是按
  目录名建的，改名即断链。目前 `The Runaway Extra…` 有工程，已由脚本自动跳过。
- **断点续传要先认领老目录**：改了新命名后，下载器如果只认新名，会把老目录当
  "没下过"整车重下（`_adopt_legacy_dir` 就是补这个洞）。

### 9.5 复合模式的语义（用户口径）

> 封面和漫画信息用**我们自己补全的版本**；章节列表**优先本地**，网络上更新的
> 章节也要**露出来**；右上角按钮在「网络 / 本地」之间切。

- 信息层：走 `comic_field_overrides`（覆盖层），网络值保留可回退；
- 章节层：本地已下 = 实心可读，网络新增 = 按源补进来，靠 `[语言][站点][组]`
  三层标签区分身份；
- 现状：**只有 network / local 两态**（`ComicDisplayMode`），"网络 ∪ 本地"
  的第三态（composite）尚未实现——见 P49 待办。

## 10. 语言的**第二落点**：记录表（P50，2026-10-27）

### 10.1 为什么目录名不够

目录名是**约定，不是所有权**。三种情况下你根本改不动它：

1. 有翻译工程的漫画 —— 工程目录按章节名建，改名即断链；
2. 源侧重新下载 —— 目录名会被源侧规则覆盖回来；
3. 别的设备/别的时间点 —— 认知不一致。

所以语言必须有一个**属于这本漫画自己的**落点：

```
comic_field_overrides.chapter_languages = { "<章节 id>": "<BCP 47 语言>" }
```

读取顺序：**记录表 > 目录名**（`_chapterGroupLabel` 里就是一行 `??`）。

### 10.2 回填时必须分清「key」和「话号」

🔴 **目录名里的数字是章节 key，不是话号。**

```
包子源：key "0".."151"  → 目录 `[zh-Hans] 0 [baozimh]` … `[zh-Hans] 151 [baozimh]`
          标题是「第1话」..「第152话」（1-based）
```

拿标题数字（1..152）去配目录数字（0..151）会**整体错位一格** ——
第 2 话的目录被标成第 1 话的语言。`tag_chapter_languages.py` 的顺序是：

1. 先按 **key 字符串精确匹配**目录数字；
2. 匹配不上才退回**标题数字**（给 key 是 UUID / 整条 URL 的源用）。

### 10.3 工具

```bash
# 按目录名里的 [lang] 段回填（默认 dry-run）
python -u tools/tag_chapter_languages.py --comic-id remote:baozi:xxx

# 整本统一（源目录完全不带语言段时）
python -u tools/tag_chapter_languages.py --comic-id xxx --all en --apply

# 只标某几话（跨源补进来的英文话）
python -u tools/tag_chapter_languages.py --comic-id xxx --set 153-157=en --apply
```

`--set` 的号码是**给人看的话号**，key 与标题数字两种写法都能命中。

### 10.4 跨源补章时 key 怎么定

跟主源统一成 **话号 - 1**：

```
包子 key 151 = 第152话    comix key 152 = 第153话
```

落进同一份 `chapters` 既不撞也不错位，`chapterDirectoryName` 反算目录名
仍然对得上（否则"已下载"判定失效，磁盘有图却显示未下载）。
细节见 **A25**。
