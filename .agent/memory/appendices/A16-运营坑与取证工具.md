## 坑1：agent-browser 取证会卡 Chromium 下载，改用 curl 兜底

- 本机 `agent-browser open` 首次启动会**卡在 Chromium 二进制下载**（实测 6 分钟无输出、无报错），无法用于快速站点查证。
- **兜底方案**：直接用 `curl` 取得等价结论：
  - 存活/重定向：`curl -s -o /dev/null -w "code=%{http_code} redirect=%{redirect_url}" --max-time 20 <url>`
  - 接口探测：`curl -s -o /dev/null -w "code=%{http_code}" --max-time 20 -X POST <api_url>`
  - 未登录重定向判断：`curl -s --max-time 20 <page> -o /tmp/x.html -w "code=%{http_code} size=%{size_download}"`
- 不要等它下载完；curl 足以判断站点是否存活、接口是否变更、目标页是否要求登录。

## 坑2：收藏页 "Not login" 是框架登录拦截，不是 bug

- 任何实现了 `favoriteData` 的源，加载收藏前 `lib/foundation/comic_source/parser.dart` 的 `retryZone` 会先查 `source.isLogged`（`data["account"] != null`）；源**有 account 配置但未登录** → 直接 `Res.error("Not login")`，**不发任何请求**。
- 与 comix.to 等站点**无关**；旧 C 盘 `baozi.data` 同样无 `account` 键 → 包子漫画源**从未登录过**（非数据迁移丢失）。
- P-DL8 已在收藏页对 `source.account != null && !source.isLogged` 的源显示 `_LoginRequiredView`（"需要登录" + "前往登录"按钮，直达 `LoginPage`，登录返回后自动刷新）。
- **不影响** `account == null` 的无需登录源（仍走原 `ComicList` 路径，零误伤）。
