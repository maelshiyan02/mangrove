# A22 · 本地漫画的翻译组显示 / 封面语言标识 / 复合主键删行

适用：本地漫画详情页不显示翻译组、要改封面命名、要把网络漫画转本地。

## 1. 翻译组的唯一来源是**目录名**

本地漫画没有源站的版本矩阵，`chapters` 是扁平字典 `{目录名: 显示名}`。组名只存在于目录名的方括号里：

```
6 [Asura Scans] [comix.to]
```

- 显示层用 `parseChapterDirectoryName()` 反解，`ChapterDirectoryRef.groups` 是组，`.site` 是站点。
- 🔴 **不要为了显示组就把扁平矩阵改成 `versioned`**。`versioned` 的 `ids` / `allChapters` 只投影每话**首个**版本，一话多组时列表里会少卡片；阅读 key 还会从 `"3"` 变成 `"2-5"`，已读标记与 `read(i+1)` 全部错位。
- 正确做法：组筛选**只过滤 `visible`（原始下标列表）**，`_displayChapters` 保持原对象。

## 2. 站点标签 ≠ 翻译组

`_siteTagPattern` 只认带点的域名，`116 [baozimh]` 会被误判成组名，整本挂一行 `baozimh`。判定统一走 `isSourceSiteTag()`：**带点域名，或 `_sourceSiteTags` 里登记过的站名**。

## 3. 封面命名**三制**：`season(N)` / `vol(N)` / `event(名)`

`[LANG][cover]<维度>(<序号>).jpg`，`LANG ∈ {CN, EN, KR, JP}` 指的是**这张图印的语言**，不是漫画国籍（韩漫的英文版封面标 `EN`）。

| 维度 | 用在哪 | 为什么是它 |
|---|---|---|
| `season(N)` | **韩漫**（KakaoPage / Naver） | 按**季**连载：一季几十话，季末打 Season Finale，休载几个月再开下一季，每开一季平台换一张主视觉 |
| `vol(N)` | **日漫** | 按**单行本卷**出版，一卷一张新封面，且卷封面常与杂志连载彩页完全不同 |
| `event(名)` | 两者都可能 | **节日贺图 / 特别插画**：平台做活动时整批换的当期图，不是连载推进 |

**三者不是同一条时间轴上的刻度**（P19 纠正 P18）：韩漫极少出漫画单行本，日漫也基本不按季换主视觉，一本漫画正常只用其中一种。P18 把 MangaDex 的 `volume` 字段当成了纸质单行本卷号，是错的——那个字段只是上传者的编号，见 §3.2。

- 排序只看一个数：`coverVersionOf()` = `max(season, vol)`，谁大谁新；**序号相同才比语言** `KR > CN > EN > JP`。贺图没有序号（返回 null），**永远排在正篇之后**——默认封面不该被一张兔子图顶掉。
- `coverSeasonOf()` / `coverVolumeOf()` / `coverEventOf()` / `coverLanguageOf()` / `coverBadgeOf()` 都只读文件名。
- 判断语言必须**看图**，不能按作品国籍猜。

### 3.1 找封面：用「韩文原名 + 英文名」，不要用中文名

中文名只在中文盗版站流通，搜出来的多是同一张无字插画。**可靠源**：

| 源 | 拿到什么 | 备注 |
|---|---|---|
| `api.mangadex.org`（`/manga?title=` → `/cover?manga[]=`） | 该作品所有已上传封面，含 volume / locale / **createdAt** | 需走代理；`cover?manga[]=` 的 `[]` 必须 `curl -g`，否则被 glob 吃掉 |
| `comix.to/title/<hid>` | 平台现行主视觉 | SSR 里 `"poster":{"large":...}`，`static.comix.to` 原图；`<hid>` 是短 hash 不是数字 id |
| `page.kakao.com/content/<id>` + **Googlebot UA** | 官方现行主封面、作品类型、권 列表 | 见 §3.2，普通 UA 只拿到 SPA 空壳 |

- 判定两张图是不是同一张：缩到 64×64 灰度算平均差，**<5 即同一张**。别靠肉眼猜。
- **createdAt 是判断"哪个是季、哪个是活动图"的关键线索**：同一分钟批量上传的一批，多半是有人事后补抓，不代表发布顺序；而单张、且贴着开播时间的，通常就是第一季主视觉。

### 3.2 Kakao 的 `[단행본]` 是**小说**单行本，不是漫画单行本

`page.kakao.com` 作品页「연관 작품」里出现的 `XXX [단행본]`，点进去 `title` 标签写的是 **`- 웹소설`**——那是原著小说的单行本（渣男 1~6권、保姆 1~5권 완결），跟漫画无关。拿它当漫画的卷封面会直接错一整层。

要拿漫画侧数据：MangaDex 条目的 `links.raw` 里有 `https://page.kakao.com/content/<id>`。该页面对普通 UA 是纯 SPA（只有空壳 meta），但**换 Googlebot / facebookexternalhit UA 会返回完整 SSR**，含 `og:title`、作品类型（`웹툰` / `웹소설`）、`og:image`（官方现行主视觉，720×1030）、以及前 25 话目录。反过来用 `og:image` 和候选封面做像素比对，就能确定**哪一张是平台此刻在用的**。

### 3.3 贺图识别：先看画面符号，再对上平台活动

韩国网漫平台的换图活动有公开新闻可查（Naver 官方新闻稿，单次覆盖 500~900 部连载）：

| 节日 | 时间 | 已核实来源 |
|---|---|---|
| 愚人节 만우절 | 4/1 | Naver 2026-04-01：约 900 部换成 SNS 概念缩略图，500 部最新免费话次加作者手绘特辑 |
| 黄金连休（含儿童节） | 5/1–5/5 | Naver 2025-04-30：「连休主角也放假」主题，约 900 部 |
| 春节 설날 | 农历 1/1 | Naver 2021-02-11：游戏角色穿韩服的「설맞이 축전」 |
| 秋夕 추석 | 农历 8/15 | 图像符号确凿：**韩服 + 柿子树 + 月兔 + 满月 + 韩屋窗棂**（月兔是秋夕专属，春节没有） |

- 樱花满屏 + 标题换成粉红手写体的，按画面记 `event(cherry-blossom)`（4 月樱花季，与愚人节同月但不等同，**不猜**具体活动）。
- 圣诞 / 万圣节 / 情人节：**没找到公开证据**，不要凭印象写 `event(christmas)`；真有素材时用 `event(名)` 记录画面，名字如实描述。
- 判据优先级：先看**标题 Logo 是否换过**（正篇是统一的立体字，活动图常换手写/渐变体），再看**画面有无季节/节日符号**，最后才看文件名。

### 3.4 快看漫画的正版竖版封面拿不到

`kuaikanmanhua.com` 详情页的 `<img class="imgCover" vw="338">` **没有 src**，由前端 JS 从带签名的接口注入；`og:image` 是 1280×800 的横版分享图（`f2.kkmh.com/image/...-w750.jpg`），不是封面。加 `-w338` / `-w540` 之类的尺寸后缀一律 404。

要拿只能逆向签名（`X-Signature`/`X-Timestamp`）或用有登录态的浏览器。搜索引擎给的中文结果噪声极大。**用户已明确中文版封面不重要，只补韩文原版即可——别在这上面耗时间。**


## 4. 复合主键不能"删了再 UPDATE"

`local.db` 的 `comics` 主键是 `(id, comic_type)`。把网络漫画转本地时：

```python
# ❌ 整本消失：删完旧行，UPDATE 匹配不到任何行
DELETE FROM comics WHERE id=? AND comic_type<>0
UPDATE comics SET comic_type=0, ... WHERE id=?

# ✅ 主键列可以直接改
UPDATE comics SET comic_type=0, ... WHERE id=?
```

这条与 A21（域库删行 cascade）是一对：**真相层删行会丢整本，镜像层删行会连带删历史**。删之前先 `cp` 备份，命名带 `bak_pXX_` 时间戳。

## 5. 转本地要同步四处 `type`

`history.db.history.type`、`history.db.reading_statistics.type`、`read_later.db.read_later.type`、域库 `history_events.comic_id`。漏一处就是"历史在库里但详情页看不到"。

## 6. 新增列必须容错读取

`alt_titles` 这类新列在老备份 / `restoreFrom` 进来的旧库里不存在。`LocalComic.fromRow` 里用 try/catch 包住解码，**读不出来当没有**，绝不能让整本加载失败。
