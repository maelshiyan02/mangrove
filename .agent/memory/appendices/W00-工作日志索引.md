## 4. 维护规则

1. 新日志文件名 = `P{编号}-{TYPE}-{主题}-{YYYYMMDD}.md`，放进**当前阶段的 worklog 目录**。
2. 可行性/调研/根因分析 → `documents/analysis/`；实施/修改计划 → `documents/plans/`；
   开场白/交接词 → `documents/handoff/`；可复跑脚本 → `documents/testing/`。
3. 新文件必须同步登记：`../../documents/INDEX.md` 对照表 + 本文件阶段表（如跨阶段）。
4. 阶段目录只在进入新阶段时新增，不改名、不重排已有编号。
