## 用法

- 找"某个决定当初为什么这么做" → 先看分卷里的**一句话**，再点进正文搜索关键词。
- 新日志追加时：取下一个空号，**同时**更新对应分卷、本导航表与 `A08`（及相关 A 附录）。
- W 编号来自本索引（工作日志），P 编号来自阶段计划/文件名前缀；两套编号并存、各自不跳号。
