## 3. 长画布（`StudioScrollCanvas` / `StudioStripPage`）

页宽来自 `LayoutBuilder` 的 `maxWidth`；`scrollToPage` 负责跳页。

### 三个地雷

1. 🔴 **画布自持 `_pages`，按 `key` 复用**（`_syncPages`）：
   - **`_stripPages()` 绝不能在 `build()` 里现场 new** —— `StudioStripPage` 持有 `decoded`，每帧新建 = 缓存根本不存在；
   - 父组件一 `setState`（滚动经 `onPageChanged` 就会触发）全页会回到"缺少页面图片"；
   - 更糟的是 `didUpdateWidget` **只比 `length`**（恒为 5）→ **永久不自愈**。
2. 🔴 **页高只有一个真相 = `_pageHeight()`**（`_StripItem` 的占位也用它）。历史错法三种：
   - `position.viewportDimension` 是**纵向滚动的视口高度**，不是页宽 → `scrollToPage` 跳错页；
   - 占位写死 420 而估算 1100 → 当前页漂移；
   - `fit` 缺 `min(…, 1.0)` → 窄图按原尺寸渲染 → 高度失步。
3. 🔴 **`StudioStripPage.dispose()` 必须推进 `token`**，否则在途解码会回写到已被逐出的页 → **bitmap 永久泄漏**；
   解码失败要加 `failed` 标志，否则每次滚动通知都去重读损坏文件。

### 性能与失效

- `studio_page` 侧另有 `_stripCache` 记忆化（省掉每帧 97×3 次 `existsSync`）；
  **项目重载 / 检测落盘后必须 `_invalidateStripCache()`**。
- `_resolvePageFile` 是统一解析入口：`inpainted → mask → original`。

## 4. 保存契约

```
原子写 ProjectWriter.save(root: workspace, keepBackup: true)
  → markSaved()
  → 失效 @bt: 缓存（LocalManager().notifyListeners()）
  → 后台「脏页增量」重渲 result/（mask/ inpainted/ 是输入，不改）
```

- 🔴 **脏页快照必须在 `markSaved()` 之前取**：
  之后取恒为空集 → `filter` 什么都不渲 → **`result/` 永久陈旧且不报错**。
- 🔴 **保存必须先产 `inpainted/` 再产 `result/`（两阶段，顺序不可交换）**：
  `writeArtifacts` 内部是**并发 worker**，把两个 kind 放进同一次调用会读到**还没写出来的底图**，
  而且**小数据量下会侥幸成功** → 属于"跑得过一次、换台机器就坏"的写法。
- `null` =「不知道」→ 全量重渲；**空集** =「确实干净」→ 一页不渲。

### Undo / 脏标记

- **Undo 粒度 = 单块快照 23 键**；`clear + addAll` 保持 map 身份。
- `isDirty` 用 **saved index** 计算。
- **拖拽只在结束时写模型**（＝1 个撤销步）；面板滑块用 `onChangeEnd` 提交。
- 保存流程**不碰 `result/` 以外的产物**（`mask/` `inpainted/` 是输入）。

## 5. 🔴 `PopScope` 的边界（P9.2 头号教训）

- **`PopScope` 只能拦住 `maybePop`**：
  `canPop` → `PopEntry.canPopNotifier` → 只被 `ModalRoute.popDisposition` 读 → 只被 `maybePop` 查；
  而 **`pop()` / `popUntil()` 走 `_RouteEntry.pop(imperativeRemoval: true)` 直接置 pop，不查 `popDisposition`**；
  `exit(0)` 更是与 Navigator 无关。
- 本应用有 5 条离开路径，`PopScope` **只覆盖 2 条**。
- 现方案：`setPreventClose(true)` **常开** + 退出收敛到**唯一**出口 `_quitThroughGuards()`（守卫说"不"就什么都不做）。
- 刻意豁免：开了托盘时 Alt+F4 ＝ 收进托盘。
- **已知缺口（非遗漏）**：**Alt+F4 / 任务栏关闭 且「最小化到托盘」关闭** → `tray.dart` 的 `setPreventClose(false)` 把关闭权交还原生，**完全不经过 Dart**；托盘「退出」同理。归属 S10/S11。
- ➜ **给编辑器加返回保护之前，先列出全部离开路径，逐条确认机制。**

## 7. 吸附

1. **必须能被看见**：回传命中的参考线并画虚线。
