## 1. 覆盖层（P11）

**表**：`comic_field_overrides(comic_id, field_key, value_json, updated_at)`，主键 `(comic_id, field_key)`。

- 存在于**域库** `mangrove.db`（`schemaVersion` 4 → **5**），不在 `local.db`。
- `comic_id` 是域库主键（`remote:comix.to:11522449`），**不是** `comic.id`（源侧 id）。
  换算唯一入口：`ComicOverrideStore.comicIdOf(sourceKey, sourceComicId)`。
- **故意不加外键**：本地漫画在 `mirrorLocalComic` 落库前就可能被编辑，加外键会静默失败。
- 值统一 JSON 编码；`value_json = NULL` / 缺行 = "没有覆盖"。

**读取三层合并**：`覆盖值 > 网络值 > 兜底`。合并只发生在
`_ComicPageActions.overlayLocalOverrides()`，**只在 `buildContent` 入口调一次**，
且 `raw.sourceKey == 'local'` 直接原样返回（本地漫画没有"网络壳"）。

**已开放覆盖的字段**：`title` / `subtitle` / `description`（P11）。
`cover_uri` / `tags` / `author` / `status` 的 key 已定义但 UI 未开。

**写入口**：`showComicOverrideDialog`（`pages/comic_override_dialogs.dart`），
只在**本地模式 + 网络漫画**时出现在 AppBar（`Icons.edit_note`）。
保存时"与网络原文一致"→ 写 null（清除覆盖），避免留无意义覆盖行。

## 2. per-comic 显示模式（P11）

- 值：`comic_field_overrides.display_mode` = `local` / `network`。
- `ComicOverrideStore.displayModeFor(comicId)`：**自己的设置优先，否则回落全局默认**。
- 全局键 `appdata.settings['comicDisplayLocalMode']` 仍然存在，**语义降级为"默认值"**
  （系统设置里已改名 `Default Local Mode`）。
- 语义升级：不再只是"章节列表隐藏未下载"，而是**信息权限**
  （网络模式看源头内容，本地模式看已下载 + 自定义）。
- 消费点：`chapters.dart`（两个视图，共用 mixin 的 `_overrideComicId`）、
  `reader/chapters.dart`（`_readerLocalDisplayMode(reader)`）、详情页 AppBar 按钮。

## 3. 封面池（P12）

**目录约定**：

```
<漫画目录>/cover/[cover]season(1).jpg
<漫画目录>/cover/[cover]season(2).jpg
<漫画目录>/cover.jpg            ← 旧布局，继续支持
```

- 常量与解析在 `foundation/chapter_directory.dart`：
  `coverDirectoryName` / `isCoverDirectoryName()` / `coverSeasonOf()`。
- IO 在 `utils/cover_pool.dart`：`listCoverCandidates` / `pickCoverFromPool` /
  `coverStillExists`。默认封面 = **季度号最大**那张；读不出季度的按文件名排后面。
- UI：`pages/cover_picker_dialog.dart`（详情页 AppBar `Icons.photo_library_outlined`），
  选中后写 `LocalComic.cover`（相对路径），**只改指针不动文件**。

### 🔴 三条路径都必须跳过 `cover/`

漏掉任何一个都会长出"叫 cover 的假章节"或把封面当某章第 1 页：
1. `scanLocalComicDirectory`（导入）
2. `refreshLocalComicChapters`（刷新章节）
3. `deriveCover` 的"首章首图"兜底

### 🔴 不能无脑重算封面

加章 / 删章 / 刷新章节三条路径都会重算封面。必须走
`_deriveCoverKeepSelection()`：旧封面文件还在就保留，失效才重算。
否则"用户挑了 season(1)，加一章就被打回 season(2)"——这类"改了又自己变回去"
的 bug 极难归因。

## 4. 章节显示名（P13）

**只改显示，不动 key。** `LocalComic.chapters` 的 key = 目录名（读图路径来源），
value = 显示名。改名等于把已下载的图弄丢。

```
49 [Rokari Comics] [comix.to]  →  第49话 · Rokari Comics
116 [comix.to]                 →  第116话      （方括号里只有源站，不算组名）
12.5                           →  第12.5话
默認 / 番外                     →  原样          （非数字开头，别硬套）
```

- 实现：`chapterDisplayName()`（`chapter_directory.dart`）。
- 源站判据：**带点的域名形状** `^[\w-]+(?:\.[\w-]+)+$`；有空格的一律当组名。
- `refreshLocalComicChapters` 用 `relabeled` 标记：显示名变了即使没有新章节也要写回。

## 5. 手抄 `LocalComic(...)` 构造会静默丢字段

`setCoverFromFile` 曾漏 `source` / `updateTime`：用户填完"来源/更新时间"再换一次封面，
两个字段被清空。已抽出 `_copyLocalComicWith(comic, cover: …)`。
**新增任何"改一个字段"的写操作，一律走它，不要手抄构造。**
