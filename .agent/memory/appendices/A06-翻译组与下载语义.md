# A06 · 翻译组 / 合集 / 下载语义

> **触发时机**：碰翻译组、章节模型、选章器、下载、缺页表**之前**。
> 上级索引：`../MEMORY.md` ｜ 相关：`A03`（目录命名）· `A07`（comix 源）

---

## 1. 翻译组信息从哪来

- ✅ **组信息已在 `local.db` 里**（`ComicChapters.toJson()` 序列化）→
  UI 显示组标签**不需要文件名标记、也不需要边车文件**。
- ❌ 例外：**本地导入的漫画是「扁平」的**（无组信息）；**`bt_` 卡的组为 `null`**。
- S7U 遗留（并入 S12/S13）：同话多组在阅读器里并列展示的问题；本地导入补组信息只能靠边车 `chapters.json`。

## 2. 🔴 章节标识与目录名

- **`downloadedChapters` 存的是 `chapterKey`**（**不是**话号、**不是**目录名）。
- 已知 bug：**选章器交出的是「索引」** → 选 B 组会被 `ids.elementAt(i)` 翻成 A 组。
- **章节目录名唯一真相 = `chapterDirectoryName(chapters, chapterKey)`**：
  下载 / 读取 / 删除 / 缺页表 / 磁盘反查**必须全部调它**（旧目录用 `migrateChapterDirectories()` 迁移）。
- 🔴 `findValidId` 必须带 `AND id GLOB '[0-9]*'`：
  `CAST(id AS INTEGER)` 会把 `bt_xxx` 变成 `0` → **导入即崩**。

## 3. 🔴 `preferDownloaded` 不能省

- 现象：只下载了**非首选组**时，阅读器取不到目录 → **空白页**。
- 解法：把**已下载的版本提到该话首位**（必须走 `versionedOrdered`）。
- 选章器形态：按组分节 + 折叠 + **默认只展开第一组**。

## 4. 下载语义

- **每章一个任务**（不是每话、不是每图片）。
- `maxParallelDownloads` 默认 **1**（上限 ≤3）。
- 图片层面走**滚动窗口并发**。
- 副标题格式：`来源 · 翻译组 · 章节名`。
- 🔴 `ImagesDownloadTask.==` / `hashCode` **必须把 `chapters` 纳入**（否则不同章节的任务会被判为重复）。

## 5. 多轮渐进超时与失败页

- **4 轮渐进超时**：`[5, 10, 15, 30] s`。
- **仅最后一轮的失败页**写进 `missing_pages.json`。
- 🔴 **失败页每一轮都必须重建新的 wrapper**（复用旧 wrapper 会把上一轮的状态带进去）。
- 阅读器侧的**缺页标识**：章节标签变红（优先级最高，见 `A02 §1`）。

## 6. 版本模型（易混点）

- 代码里已有的 `ComicChapters.versioned` / `versionedOrdered` 是 **S7U 的「同一话多个翻译组」章节模型**。
- 它与 **S13 计划里的「同一话左右对照原版/译文」** **不是一回事** —— 讨论时不要混用。
