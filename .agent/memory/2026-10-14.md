# 下载缺页根因修复 + 关闭软件安全暂停保护（2026-10-14 后续）

## 背景
用户反馈一本漫画大量章节缺页，怀疑是下载中途关软件导致连锁反应。

## 根因（已核实）
- 关窗路径 `TrayController._quitThroughGuards()` 在「非最小化到托盘」时直接 `exit(0)`，**完全没碰下载任务**。
- 在途图片 `writeAsBytes` 直接写最终文件名、非原子 → 被杀时留下**半截最终文件**。
- 重启续传用 `_existingPageIndexes()` 只按文件名前缀判存在、不校验完整性 → 半截文件被当已完成 → 缺页永久固化。
- 被杀那章的 `_flushMissing()` 没机会执行 → 连「修复下载」（只重拉 missing_pages.json 登记项）都救不回。

## 修复
