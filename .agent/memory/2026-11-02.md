## 3. 经验

- 中文文件名批量核对必须 `git -c core.quotepath=false`，否则 rename 比对全部乱码。
- 批量改引用时，**前缀规则要靠前、裸文件名靠后**；否则会把 `docs/xxx` 错替换成无法解析的相对路径（本次两个 dart 文件踩到）。
- 阶段目录隔离能消解编号重号，不必为了唯一性重排（重排会打断大量交叉引用）。
