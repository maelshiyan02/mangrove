
## 2026-10-04 晚：comix.to 全站 CF + baozimh gatekeeper 加固应对
- **用户报告**：comix.to 阅读图片全 403（DioException）；baozimh 报"需要Cloudflare验证"。
- **探测结论（curl + Chrome headless 实测）**：
  - comix.to 整站上 CF managed challenge（主站 API 走常驻 webview 仍可用，截获到新鲜图片 URL）。
  - 图片 CDN 换成轮换域（447.joshuanotes.site / thekyleblog.site / softstylemarket.site 等），是**按 TLS 指纹拦截**的 WAF（1020 "Sorry, you have been blocked"），带 Referer/完整浏览器头都无效；真实 Chrome headless 直接 200（连 Referer 都不用）。旧域 ek10.media-processing-lab.site 已被 CF ToS block（整 zone 废）。
  - 封面域 static.comix.to = CF managed challenge（dio 也拿不到）。
  - baozimh：www.baozimh.com 302→cn.bzmgcn.com→cn.cnbzmg.com，gatekeeper PoW 提到 difficultyBits:12 / computeMs:120000（约 2 分钟），headless 验证 45s 必超时。
- **修复**：
  1. cloudflare.dart：headless 验证 deadline 45s→200s；新增 gatekeeper 失败态（data-state="failed"）提前退出。
  2. comix_client.dart：新增 `_ComixImageWorker`（独立常驻离屏 WebView，串行队列）+ `ComixClient.fetchImageBytes(url)`：导航到图片 URL（真实 TLS 过 WAF + 建同源上下文）→ 页内 `fetch(location.href, {referrer:'https://comix.to/'})`（命中浏览器缓存）→ FileReader base64 回传；带 90s 挑战重试循环（static.comix.to 的 challenge 自动过后持久 cf_clearance）。
  3. images.dart：`_loadComicImage`/`loadThumbnail` 支持 `configs['viaWebview']==true` 走 WebView 取字节。
  4. comix_to.js v0.6.0：onImageLoad/onThumbnailLoad 返回 `viaWebview: true`；已 node --check + 同步 APPDATA。
- **构建**：BUILD_OK（app.so 22:23，18.3MB）。踩坑：loadThumbnail 里 viaWebview 分支用了还未声明的 requestUrl → analyze error，改用 configs['url'] ?? url。
