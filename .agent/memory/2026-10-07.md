### 改了什么（3 文件）

### 关键决策
1. 🔴 **`pageKey` 必须是 `required`** —— 可选的话"忘记自己属于哪页"的命令会**静默掉出脏页集** → `result/` 磁盘陈旧而 JSON 说新的（本仓库反复踩的静默分叉类）。`required` 让未来 P0-2/P1-5 的新捕获路径**编译期就暴露**。
2. **`dirtyPages` 重算，不做增量集合**：`_savedIndex` 之后的 undo 栈 ∪ （redo 栈 ∩ 仍有未保存改动的页）。增量实现（push 加/undo 减）必须逐条特判 undo/redo/`limit` 截断，漏一条就是"假脏白重渲"或"漏脏不重渲"。
3. 🔴 **必须在 `markSaved()` 之前取快照** —— `markSaved` 正是把页变干净的那一步；之后取恒为空 → `filter` 等于什么都不渲 → `result/` 永久陈旧且无任何报错。
4. **`null` / 空集语义分明**：`null`="不知道"→全量；空集="确实没脏页"→一页不渲。（实测首测就靠这条区分。）
5. **实现期自我修正**：初版给基类加了 `beforeState`/`afterState` 想比对页内容，写到一半发现**逻辑不需要比较内容**（只需集合成员判断）→ 两个成员删掉。已登记的取舍："改了又改回"净变化为 nil 的页仍会多渲一页（刻意不省）。

断链**三处且全静默**（不报错、只是样式被丢）：① `toTranslatedRegion()` 只填 5 字段｜② 🔴 **`result_renderer` 重建 `TranslatedRegion` 时也只抄 5 字段（最关键，工作室保存走它）**｜③ `page_renderer` 写死 `w500/1.2`、字体族根本没传。

🔴 **四个单位陷阱**（都在 `page_renderer`）：
- `font_size` 是**上限**不是替换值（否则 20px 框里要 40px 会溢出气泡）
- `letter_spacing` 是**倍率**须转 `(v-1)em`（当像素传会把 CJK 挤在一起）
- `stroke_width` 是**绝对 px**，不再随字号缩放（旧路径 `max(1.5, size*0.14)`）
- FT `vertical` **压过**竖排启发式（旧逻辑会把"又高又CJK 的横排译文"静默转竖排）

`_scaledFontStyle(style, scale)` 只缩放**像素类**字段，字重/对齐/透明度/角度原样 —— 不缩放会让文字相对框大 2.5 倍。附带做 RTL Unicode 区段检测（`rune<0x0590` 跳过，否则一个杂散字符能把英文判成 RTL）。

### P9.5 · P0-2 fromOcr

`TextBlock.fromOcr(OcrBlock)`。🔴 **必须在 `createDefault` 之上 mutate**（P9.0 §七.3 硬要求）—— 两调用方键集不得分歧，否则同页混用即破零字节 diff。

## 🔴 21:47 收尾：headless 判据修复（`-532265403` 之谜查清）

上一轮把「`headless.out` 为空 + `%ERRORLEVEL%` = `-532265403`」报为**未解释**。本轮查清 —— 结论是**两处观察都要更正**。

### 1. 「输出为空」是**时序误判**

复核时 `builds/headless.out` 实际是 **23,437 字节的完整写入**，含全部 122 条 `[CLI PRINT]` 与收尾行。
旧观察不成立，「输出丢失」不需要再排查。

### 2. `-532265403` 不是噪音，是**恒定值**

对照实验（同机、同会话，只差命令行）：

| 命令 | CLI 自己怎么判 | `%ERRORLEVEL%` |
|---|---|---|
| `edit-check ComicLibrary/projects/S9Fixture/imgtrans_S9Fixture.json` | `"status":"success"` · **PASS (122 checks)** | `-532265403` |
| `project-check`（**无参数**） | `"status":"error"` · needs a project file | `-532265403` |

**成败两端退出码完全相同** ⇒ 它是「引擎在**无渲染表面**下收尾」的产物，只证明**引擎跑起来了**、不含成败信息。
⇒ 本文档早先「任务被强杀」的归因**是错的**（已就地更正）。
⇒ **拿它当判据 = 永不失败。**

### 3. 顺手挖出工装的一处**永久假绿**

`run_headless_task.py` 末尾原本是：

```python
code, _ = run(sys.argv[1:])
subprocess.run(["cmd", "/c", "exit", str(code)])
sys.exit(0)          # ← 恒 0
```

`cmd /c exit N` 只给**子进程**设退出码，父进程照样 `sys.exit(0)` ⇒ **调用方永远看到 0**。
叠加上面那条：「`headless.out` 被清空」与「检查全部通过」**不可区分**。

**修法**：判据改为**输出里最后一条** `[CLI PRINT] {"status":"success"|"error"}`（`headless.dart` 的 `cliPrint` 收尾行；
过程行是 `"running"`），返回 **0 / 1 / -1（等输出超时）**；删掉那段无效的 `cmd /c exit`。
**没有收尾行也判失败**（空结果判 FAIL）。`=== HL_EXIT=` 仍打印，但降级为「引擎确实跑到收尾」的凭据。
