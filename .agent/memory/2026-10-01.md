### 关键发现（本次最有价值的三条）
1. **API 签名 token 参数名是 `_` 不是 `__`**
   验证：`?_=abc` → `Invalid token.`；`__`/`token`/`sig` → `Missing token.`。
   v0.4.x 全程检查 `"__="` → 所有 API 路径静默降级 DOM → 慢 + 不全。
2. **token 绑定完整 query string**：加任何参数都 Invalid → 不能复用 token 自拼分页 URL，
   必须让 SPA 自己发（点分页按钮 / 导航 browse 页）后截获。
3. **响应可能加密**：`{"e":"fktAPNu-..."}`（浏览器内是明文，WAF 对可疑客户端降级加密）。
   故加 JSON.parse 明文载荷通道（与 BT 的 `parse_page_urls_from_capture` 同思路）。

附带发现：`/api/v1/user/chapters/{id}/state` 路径撞车旧匹配器 `/chapters/\d+` → 抓错请求 → pages 空。
另外阅读器是 **Swiper slides 虚拟化**（同屏 3~5 张，不是懒加载）→ DOM 兜底最多 4 张。

### 修复（comix_client.dart / comix_to.js v0.5.0 / images.dart）
- 匹配器锚定 `/api/v\d+/chapters/\d+$` 且排除 `/user/`
- 双通道：`_captureOrPayload`（fetch 截获 + JSON.parse 载荷），记 status 与 body 预览
- 章节分页：点按钮让 SPA 重签 token 后截获（去重 by id/url）
- `_lastCaptureUrl` 原样重放兜底；`_hasToken()` 用 queryParameters 判 `_`
- `_extractImageUrls` 兼容 result 包装 + baseUrl 拼接
- DOM 兜底：轮询到数量连续 3 次不变 + 强制 eager + 多选择器
- comix_to.js：`onImageLoad` 带 `Referer: https://comix.to/` + `timeoutSeconds: 90` + cache-bust 重试；加 `onThumbnailLoad`
- images.dart：`_loadComicImage` 支持源级 `configs['timeoutSeconds']` 覆盖默认 30s
