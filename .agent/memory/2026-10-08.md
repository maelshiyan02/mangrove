### B. 🔴 mask 产物 = 0 的根因（三条，缺一不可）

1. **没有任何代码生产 mask**。`ProjectWriter.save()` 的 `ensureArtifactDirectories`
   （`project_writer.dart:269-277`）只 `create(recursive:true)` **建空目录**；

   kinds 只出现过 `inpainted` 与 `result` ⇒ **`ProjectArtifactKind.mask` 只活在枚举与目录名里**。
2. **掩膜根本不落盘**。`renderInpaintedPage`（`result_renderer.dart:151`）调
   `TextInpainter.erase(image, eraseRects)`；`erase` 内逐 rect 调 `computeMask`
   （`inpaint.dart:28`）算出掩膜，**用完即弃**。`computeMask` 除 `erase` 外无其它调用方
   ⇒ 掩膜只活在内存（类型 `TextMask` = 局部窗口 + `Uint8List mask`）。
3. **那 Error the Echo 的 97 张是哪来的** —— 不是我们造的。
   page key = `0/1.webp`（带章节目录），`mask/0/1.png` = **PNG 8-bit colortype 0（灰度）
   690×1347**（FT 格式），mtime **Sep 26 19:27**，早于工程 json（Sep 29）与 Mangrove 全部工程能力
   ⇒ 外部 FT/BT 会话的产物。

### C. mask 的真实角色：**只读兜底**，不是生产物

`displayPath` / `_resolvePageFile` / `_resolveBase` 把 mask 当「**原图丢失时的最后一张底图**」
（`project.dart:334`、`studio_page.dart:584`、`headless_pipeline_check.dart:613`）。
Error the Echo 的 `directory`（原图）已不存在 ⇒ 正是这个用例：**没有那 97 张 mask，
整个工程一页都显示不出来**。所以它们是**被消费的存量**，不是我们要补的产出。

⚠️ 语义差（补 mask 生产时必读）：FT 的 mask 是**整页单通道灰度**（白=要擦的字）；
我们内存里的 `TextMask` 是**逐 region 的局部窗口**（`computeMask(image, region)`）。
⇒ 补生产不是把内存那份 dump 出来，得按 FT 语义**拼整页**（A08 §4.10.2 待拍板 18）。

## P10.10 ① 自定义翻译脚本（script_translator.dart）—— ✅ 已交付 + 验证

### 做了什么

  `builtInFallback` 是可替换 static 函数，便于 headless 离线验证回退。

### 设计决定

1. 🔴 失败/超时**必须回退内置引擎**，绝不能让管线挂起或丢字 —— 这是与上游最大的行为差异点，
   用 `builtInFallback` 缝把"随机失败"变成"确定性回退"以便逆向验证（headless 换缝为离线确定实现）。
2. 超时靠 `Promise.race([userPromise, stop.future])`：用户脚本永不 resolve（死循环/await 永不返回）
   ⇒ `stop.future` 在 1s 后 resolve ⇒ race 胜出 ⇒ 抛超时。
3. 长度不符（短脚本返回 1 项喂 3 项）直接抛 → 由 `builtInFallback` 接住。
