1. **诊断断言**：`ComicChapters.versioned({'51':[ComicChapterVersion(chapterKey:'51 [MagusManga] [comix.to]')]})`
   上 `chapterDirectoryName` 返回**原样带组名**（versioned + group 空 → `parseChapterTitle` 认不出方括号 →
   fallback 原样返回 chapterKey），故字面命中、新旧逻辑都返回正确 key。加「无组回退 key」修复后
   故障对照 `broken_would_pass=true` ⇒ 回退惰性、无意义。
2. **决定性实验**：`data/local.db` 的 `downloadedChapters` 临时 54→50，跑官方 `page-reconcile 2`，
   仍 `50→50 / 0 newly`；51–54 磁盘各 93/101/96/85 张图。已自动恢复 54。
   取证 `_work/p73_probe_{reconcile.py,result.json}`、`_work/p73_diag.json`。
3. **真因**：id=2 `comic_type=0=ComicType.local`，`reconcileDownloadedChapters` 首行
   `if (comic.comicType == ComicType.local) return 0;` 跳过全部对账 —— 与组名解析无关。
   local 漫画目录名即 key、下载时即登记，不走 reconcile 自愈，属设计边界非缺陷。
