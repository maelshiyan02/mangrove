## 18:10 扩展名统一 + 全本 50 话补齐

**扩展名事故根因**：comix 的图片 URL 一律带 `.jpg` 后缀，实际返回 WEBP。
旧版按 URL 猜扩展名 ⇒ 全库 877 个 webp 被存成 `.jpg`；重下时扩展名算法
不同就新旧并存（Ch.49 一度 95 页→190 个文件，阅读器显示 190 页）。

**修法**：`sniff_image_ext()` 按文件头判断（RIFF+WEBP / FFD8 / PNG8 / GIF），
替换三处 URL 猜测点（`save_payload` 主路径、dataURL 兜底、`download_image` 落盘）。
改名用 `os.rename`（不是删除，绕开 safe-delete 守卫）。

**改名前预检**（关键，不能一把梭）：全库 `.jpg` 分两类 —
- 877 个是**假 jpg**（内容是 WEBP）→ 改名
- 1340 个是**真 JPEG**（8 个 `cover/[cover]season(N).jpg` + cos写真 1332 张）→ 保持不动
改名后全库 `.webp→WEBP 29260` / `.jpg→JPEG 1340`，**名实不符 0**。

**字节级验收**：29260 个 webp 的 RIFF 声明长度全部等于实际文件大小，0 损坏。
487 个小于 1KB 的文件全在 `扔掉的渣男`（baozimh），是 640 宽长图切片的边缘
片段（`640x1`、`640x4`），源站特性，不是损坏。

**全本补齐**（The Runaway Extra and the Obsessive Duke，hid=6emnz）：
Rokari 组 49 话 + Lux Manga 第 50 话 = **50 章 / 4530 页 / 1.31 GB**，
页数全部等于站点节点数，页号 1..N 连续，非 webp 文件 0。
